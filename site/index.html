§03自动归档

① 她自己记

你不用记得去告诉她「要记住」。每一轮结束，一个安静的子代理会读一遍刚发生的事，把值得留的按主题归档——不是往一堵墙上继续堆。等这些内容重新变得相关时，宿主会在上下文的固定边界把它们注入进去。模型不需要「想起来去查」，你的前缀缓存也不会被打散。

  • 你没有任何「记得要做」的动作——根本没有一个会忘的保存键
  • 按主题成组，一周后翻出来仍像笔记，不是一堆流水
  • 固定边界注入，前缀缓存友好，不会每轮全量重算
  • 窗口写满时她写一份交接账本，而不是把自己压缩掉
怎么核

打开面板的日志页签，每条自动归档都带时间戳，并标明来自哪一轮。

§04可审计

② 每条都查得到

查不到源头的记忆就是传闻。每次唤起都带完整证据链：哪几条被激活、依据是什么、分数多少。你可以在「唤起回顾」里逐条评分——评分会回流到晋升判定，所以差了会越来越安静，好用的会越来越牢。没有黑盒，也没有任何东西离开你的磁盘。

  • 你能在一条错记忆悄悄影响后面几个月之前就抓出它
  • 评分就是反馈回路——技能就是这样挣到晋升的
  • 凭据不进提示词：写入前卫生检查会剥掉
  • 一切都在你本地磁盘；没有账号，没有云端
怎么核

唤起回顾页签 → 任选一次唤起 → 能看到它的来源与评分；改或删立即生效。

§05三层分工

③ 三层分工

她记的东西分三层放，放在哪一层，决定它怎么进入模型。硬规矩每一轮都进——没有例外。项目笔记住在常驻目录里，随手可用但不吃窗口。每日日志平时不占地方，真需要的时候才被拉进来。

每轮 用户级硬约束

「绝不要 X」「永远用中文答」——你自己定的。

到达方式：每轮无条件注入（不做相关性判断）

命中即用 项目级笔记

决策、架构、约定——本来要反复解释的东西。

到达方式：常驻目录 + 命中即用（≤400 token）

按需 每日日志

今天发生了什么，带时间戳。

到达方式：仅按需检索（不进窗口，直到被需要）

你把东西放进哪一层，本身就是调度决策。你不需要手工调注入策略。

怎么核

设置页显示每一层当前占多少 token；规则层有可视化编辑器；笔记层显示常驻目录体积。

§06日历

④ 她替你记日子

截止日期、约好的时间、顺口一说就忘的承诺，都是在聊别的事的时候被顺手记下的——「周五交报告」「下周给你发过去」。它们会带着解析好的日期进日历，并在日期到之前回来找你，不是之后。

  • 明确日期：「10 月 4 日前」「30 号」
  • 相对日期：「下周」「三天后」——按今天换算
  • 时间与象限：截止时刻和重要度一并记下
  • 你对别人许的承诺，不只是你自己的任务
怎么核

问一句「我最近有什么安排」，她会从日历文件里读回来——那个文件你自己也能打开看。

§07迁移与隔离

⑤ 能搬，也不串味

如果你已经在别的 AI 工具里干过活，那段历史不用重来。她会扫描 WorkBuddy、CodeBuddy、Claude Code、Codex、ZCode、Kimi Code、TRAE 留下的记忆，按来源分别导入——进哪些你挑，事后也能把一个来源整个撤掉。另一半是反过来的：并行的工作区和会话各自保留自己的召回决策与索引缓存，你跟她讲过的工作上的事，不会串到另一个小项目里去。

  • 扫描是只读的，在你点确认之前不会写任何东西
  • 按来源分列，进哪些你挑
  • 一个来源可以整个撤掉
  • 全局层（硬规矩）是故意共享的——那是你的长期约束；其余全部按工作区隔离
怎么核

设置 → 外部记忆，会先列出检测到的每个来源及其路径与体积，在你点确认之前不会写任何东西。

§08写入闸门

⑥ 脏东西进不来

一个会写垃圾的记忆插件还不如没有。每次写入都先过闸门：乱码、卡顿输出、JSON 形状的注入都在那里被拦下；任何像凭据的东西在进入提示词之前就被剥掉。在那之上，每个功能是独立开关——你可以让它全自动跑，也可以只关掉某一项、其余照旧。

闸门拦三类：乱码 · 卡顿与重复输出 · JSON 注入 → 丢弃 + 留痕（不静默）

  • 关掉提醒不影响召回；关掉召回不影响规矩（开关互不牵连）
  • 无人值守模式整圈自动跑、不弹任何确认，挂着机也能用
  • 任何模型开箱可用：词法档 0 GB 起步，内置 JS 语义档约 130 MB
  • Python int8 进阶档（约 563 MB）是向导式可选安装，永远不是前置条件
怎么核

设置里每个功能各占一行、各有独立开关，点一下标签立刻翻面。

§09亮点页入口

三维档案终端

把它当成一间屋子，而不是一页纸。

三维档案终端把同样的内容变成一个能走进去的阵列：五列、四十份档案，方向键移动，拖拽环绕。选中的卡片会向镜头抬起，解密线随之合拢。它读的是和本页同一份数据——是同一个插件的另一种看法，不是另一个插件。

需要 WebGL 当前施工中

不支持 WebGL 时，自动退回本页这种可读版——信息不丢，只是没有三维呈现。

§10安装

三步装好

  1. STEP 01

    安装

    pnpm add @a9i5k4/dsh-auto-memory@latest
    npm i @a9i5k4/dsh-auto-memory@latest

    提示：pnpm v11 的 minimumReleaseAge 默认 24 小时，可能拦下刚发布的版本——设为 0 或写死版本号。

  2. STEP 02

    重启 DSH

    侧栏出现「记忆」入口。无账号、无云端、不上传任何东西。

  3. STEP 03

    30 秒验证

    说一件带日期的事（「周五交报告」），再问「我最近有什么安排」。日期答得出来，整条链路就是通的。
