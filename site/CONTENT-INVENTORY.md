## 页面总目标（一句话）

让一个**已经在用 DSH 的人**在 60 秒内相信三件事，然后去装：

1. 这个插件**自己会记事**，不用你提醒它「记得记一下」；
2. 它记的东西**你能查、能改、能删**，不是黑盒；
3. 装它**没有代价**：零运行时依赖、无账号、无云端、BSD-3、三平台。

页面的隐含读者分层：
- **L1 还没听说过的 DSH 用户**（看 SHEET 01–02 就该决定要不要往下看）
- **L2 正在评估要不要装的人**（看 SHEET 03–05 判断「机制靠不靠谱」）
- **L3 已经决定装的人**（直接跳 SHEET 08 抄命令）
- **L4 怀疑派**（只看 SHEET 07「已知边界」——这一节是给他们的信任凭证）

## SHEET 01 · 总览（#hero）

**说给谁**：L1，第一屏，5 秒内。

**一句话主张**：记忆不该活在上下文窗口里；该想起的自己会浮现，且每次浮现都有据可查。

**支撑事实**：
- 中文主标题「无问自忆，记忆不断线。」／英文 "She remembers, unbidden."
- 副文案（现有）：记忆放在上下文窗口之外；上下文写满时，她不再把自己压缩成摘要——**合上一本写满批注的笔记，翻开新的一页**。
- 安装命令：`pnpm add @a9i5k4/dsh-auto-memory@latest`
- 四枚事实芯片：`v3.0.0` · `BSD-3-Clause` · `runtime deps 0` · `Win / macOS / Linux` · `中英双语`

**现状证据**：
- 右栏不是截图，是一张**内联 SVG 线稿角色**（鲸鱼娘：呆毛 / 头鳍 / 鲸尾 / 白米饭碗），带工程标注（画布 1200×1200、头顶安全区、角色高≈900、锚点、色板图例）。
- 图注诚实写着「序列帧待交付」「背景层 60FPS」（见下方缺陷 D4）。

**待你拍板**：
- **①** 首屏右栏应该是「角色插画」还是「真实界面截图」？现在是一张**角色定妆稿 + 尺寸标注图**，它其实在说「我们的美术规格」，而不是在说「这插件长什么样」。对 L1 来说，界面截图的说服力通常更高。
- **②** 副文案里的「一本书」比喻要不要保留（它和插件面板的「笔记 / 白板 / 账本」术语体系是自洽的）。
- **③** 首屏要不要出现 GitHub star 数 / npm 下载量（目前没有，也就没有社会证明）。

## SHEET 02 · 数据流（#flow）

**说给谁**：L2，回答「它到底怎么运作」。

**一句话主张**：记忆**不是模型去查的**，是宿主在固定边界自动注入的——所以不需要你下任何指令。

**支撑事实**（四段流水线 + 一条回流）：

| 环节 | 中文 | 一句话解释（页面现有原文） |
|---|---|---|
| ① | 观察 OBSERVE | 每轮静默评估 · 自动记账 |
| ② | 检索 RECALL | 证据链 · 可评分 · 三态放行 |
| ③ | 注入 INJECT | 常驻目录 ≤800 tok · 缓存友好 |
| ④ | 固化 CRYSTALLIZE | 晋升闸门 · SKILL.md 导出 |
| 回流 | EVIDENCE LOOP | 跨会话证据累积 → 技能固化 |

**两段正文**：
- 记忆从不靠模型「想起来」。宿主盯着上下文，在固定边界自动注入召回——**前缀缓存友好**，不需要任何指令。
- 每次唤起都带**完整证据链**：可在「唤起回顾」逐条评分，逐条可查、可改、可删。技能由跨会话证据通过晋升闸门固化而成。

**现状证据**：SVG 流程图，四节点 + 底部虚线回流，图注「动效仅进视口播放」。

**待你拍板**：
- **④** 「前缀缓存友好 / ≤800 tok / 三态放行 / 晋升闸门 min-sessions」这些**是给工程师看的词**。页面现在的定位偏「工程冷静体」。要不要在每张图下面补一句给普通人的人话（例如：「相当于她只在固定的地方贴便利贴，不打断模型的思路」）？
- **⑤** 这一节**没有一个数字来自实测**（800 tok 是设计值还是实测值？）。要不要补真机实测数字？

## SHEET 03 · 记忆结构（#structure）

**说给谁**：L2，回答「东西存在哪、会不会丢、能不能改」。

**一句话主张**：三层注入面 × 三个库 × 一条晋升管线；一份 `MEMORY.md` 字节，三种消费方式。

**支撑事实**：

左栏「注入面」（每轮进上下文的东西）：
| 层 | 名字 | 承诺 |
|---|---|---|
| 顶层 | 用户级硬约束 RULES | **每轮无条件注入** · 面板可视编辑 |
| 中层 | 项目笔记 NOTES | 常驻目录 ≤800 tok · 语义索引自愈 |
| 底层 | 每日日志 LOGS | 按需检索 · 超限折叠后退回归档 |

右栏「记忆库」（落盘的东西）：
| 库 | 名字 | 承诺 |
|---|---|---|
| 事实库 FACT | 治理式写回 · 状态标记 |
| 情节库 EPISODIC | 巩固链路 · 时间检索臂 |
| 技能库 PROCEDURE | **模型直写通路** · 风险分级 · 审批队列 |

晋升管线：`observed → candidate → validated → active → SKILL.md 导出`（active 用品牌蓝高亮）
底部两行补充：
- 水位感知 WATER-LEVEL（**实验 · 默认关**）— 0.80 阈值标记
- `MEMORY.md` 一份字节 · 三条消费方：整篇注入 / L0 按锚点切条 / 语义语料 digest

**现状证据**：SVG，含斜线剖面图例（= 归档/压缩区）。

**待你拍板**：
- **⑥** 这是全页**信息密度最高**的一节，8 个专有名词一屏砸下来。**要不要拆成两节**（「进上下文的三层」+「落盘的三个库」）？
- **⑦** 「observed / candidate / validated / active」四个英文状态名要不要中文化（面板里已经中文化了，见 SHEET 07 上下文）。
- **⑧** 水位感知是实验特性且默认关——**放在主结构图里是否合适**？（也可以只在 SHEET 07 边界里提。）

## D1 · 界面截图被拉伸约 3 倍（唯一「比例不对」的实锤）

`site/index.html` 给三张图写死了 `width` / `height` 属性，**三个声明值与图片真实尺寸全部不符**：

| 图片 | HTML 声明 | 图片真实尺寸 | 实际渲染 | 渲染宽高比 | 真实宽高比 | 变形倍数 |
|---|---|---|---|---|---|---|
| `panel-overview.png` | 860 × 645 | **1280 × 720** | 369 × 645 | 0.572 | 1.778 | **压扁 3.1×** |
| `settings-zh.png` | 860 × 1075 | **723 × 722** | 369 × 1075 | 0.343 | 1.001 | **拉长 2.9×** |
| `workspace-map-zh.png` | 860 × 645 | **393 × 717** | 369 × 645 | 0.572 | 0.548 | 误差 4%（基本正常） |

后果：SHEET 06 在页面上是三根**又高又窄的条**，概览页和设置页完全无法辨认。这就是你看到的「比例不对」。

## D2 · 档案终端 canvas 后备缓冲尺寸错误

`#termCanvas` 的 CSS 尺寸是 **681 × 430**，但 `canvas.width/height` 属性仍是浏览器默认的 **300 × 150**（探针读数 `attr=300x150`，`后备匹配=false`）。线框阵列会被放大到 2.3 倍渲染 → 糊。另外探针在首屏读到的 canvas 采样为全透明（`blankCanvases: 1`），符合「终端区在视口外、尚未初始化」的预期，但需要一次真实滚动验证。

## D3 · 全页内容默认 `opacity: 0`，靠滚动才浮现

`site/assets/site.css:355` `.reveal { opacity: 0; transform: translateY(10px); }`，`site/assets/site.js:39–50` 用 `IntersectionObserver`（`threshold: 0.15`）加 `.in` 才浮现。32 个 `.reveal` 全部初始不可见。

- 首屏两个（`.hero-copy` / `figure.stage`）实测拿到 `in=Y`，说明观察器**会**触发；
- 但 4 个视口下 `.reveal.in` 都只有 **2 / 32** —— 页面**只有第一屏有内容，往下全是空的**，直到你滚动。
- 失效场景：`<noscript>` 有兜底（`<noscript><style>.reveal{opacity:1}</style></noscript>`），`prefers-reduced-motion` 也有兜底（`site.css:364`）。所以**真实浏览器里滚一下就会出来**；但**任何不滚动/合成器不推进的场景（headless 截图、部分内嵌预览、iframe）就只剩一个空页**。

这解释了为什么我截图看到的和你看到的不一样，也解释了「看不到」的体感来源。
