## 触发与实际行为

worker 对满 token 文档块执行 build_doc_ids 再 encode_ids。

build_doc_ids 添加 prefix/suffix 并截正文，encode_ids 再包装一次；下一块按原 chunk 步长推进，截掉 token 永久跳过。

    def build_doc_ids(self, chunk_ids, max_total=512):
        """Wrap chunk token ids with the model's special tokens exactly once,
