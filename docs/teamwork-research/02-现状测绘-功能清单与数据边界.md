**取证口径**：本卷所有数字与路径均来自 2026-09-25 夜对本仓 `lib/` 的只读解析（Node 脚本读取源码，非人工目测）。标注【实测】者可直接复核。

## 四、数据边界：三层作用域（同步设计的原点）

```
┌──────────────────────────── 本机私有（永不离开设备） ────────────────────────────┐
│  polling-heartbeat.json  update-check*.json  workbench.json  auto-continue-done  │
│  recall-stats.json（个人命中率）  subagent/session 状态  模型缓存  venv          │
│  *-pre 遗留目录（迁移残留）  .bak 备份                                            │
└──────────────────────────────────────────────────────────────────────────────────┘
┌──────────────────────── 个人云（跨设备跟随人，不进团队库） ──────────────────────┐
│  个人的 workspaces/<ws>/ 日志与反思   个人 CALENDAR.md 私有条目                   │
│  个人 notes 草稿   个人 tokens/偏好（如主题选择）                                 │
└──────────────────────────────────────────────────────────────────────────────────┘
┌──────────────────────── 团队共享（进团队库，受治理） ────────────────────────────┐
│  MEMORY.md（用户级规则 → 团队规则库）   hub/facts.json（团队事实）               │
│  evidence/（证据）   hub/procedures.json + 工作区 procedures（团队技能）          │
│  handoff/*.md（交接账本 + PLAN 白板）   团队日历条目  召回审查的团队聚合          │
└──────────────────────────────────────────────────────────────────────────────────┘
┌──────────────────────── 派生数据（不搬运，重算） ────────────────────────────────┐
│  向量/嵌入  L0 索引  sidecar 看板索引  重要性评分  覆盖率统计                     │
└──────────────────────────────────────────────────────────────────────────────────┘
```

**判据（可直接写进实现）**：任何一条数据，先问「它是不是**派生**的」——是派生就**永不搬运，只重算**；这是把同步面压到最小的第一刀。

## 五、关键接口契约样例（同步改造要接的点）

### 5.1 路由注册（56 条同形）

```js
// lib/index.js —— routes 数组内的每一项
{ state: '/api/dsh-auto-memory/state', ... }
```

### 5.2 工具注册（唯一注册点 `lib/index.js:14636`）

```js
disposers.push(ctx.tools.register(tool))
// tool 形状：{ name, description, parameters: {type, properties, required}, output:{schema, render}, execute(args, exec) }
// 19 个工具：15 memory_* + 4 calendar_*
```

### 5.3 数据目录收口（`lib/datadir.js`）

```js
export function memoryDir(name, homeFn) { /* 去 pre 迁移：不 move、只增量补齐、fail toward duplication */ }
// 实测 6 个域：workspaces / hub / evidence / semantic / index / degrade
```

**同步含义**：`memoryDir()` 是**唯一的物理路径出口** ⇒ 上云同步只需在**这一个函数之上**加一层「作用域判定」，不需要改 56 条路由。

## 六、本卷结论（给后续卷的三条硬约束）

1. **同步面 = 4 类数据（共享 / 个人云 / 本机私有 / 派生）**，不是「全部文件」。派生数据永不搬运。
2. **收口点只有两个**：路径出口 `memoryDir()` 与注册出口 `routes`/`tools` ⇒ 同步改造可以用「中间件式」增量落地，**不必重写 56 条路由**。
3. **必须显式排除的黑名单**：`*-pre` 遗留目录、`.bak-*` 备份、心跳/更新检查/子代理投影缓存。不排除会把历史垃圾同步给全团队。
