## 二、旧调研的核心结论（省去重读，直接继承）

### 2.1 「人无我有」五条差异化（A 卷结论，本轮继续作为卖点骨架）

1. **记忆生命周期治理**：作废的记忆「返回但标记」，而不是删除（`superseded` / `retracted` 状态可见、可追溯）。
2. **防记忆劫持**：让「无模型参与的记忆写入」结构性不可能（写入走唯一门 Gate）。
3. **「失败与弯路」是一等公民**：跨人接续时继承的是**排除项**，不只是结论。
4. **可信度可量化**：技能晋升要跨会话证据，证据量公开可见。
5. **团队同步的冲突面控制**：物理分文件 + 写入侧无条件保护。

### 2.2 同步架构主线（B 卷 §4 结论，本轮沿用）

- 主线 = **权威服务端 + CDC（变更数据捕获）**；CRDT 暂不采用。
- 「实时」落到指标：文本/状态 ≤5s；词法索引 ≤5s；**向量 ≤5min 异步**（两阶段：先写文本立即可见 → 后台补向量）。
- 「实时同步对向量编码难不难」的答案 = **不难，瓶颈在冲突与一致性，不在嵌入计算**。

### 2.3 上一轮已拍板（用户裁定，本轮默认继续有效）

| 裁定 | 内容 | 本轮是否有变化 |
|---|---|---|
| 裁定 1 | **登录由宿主提供，插件不自建账号体系**（插件只做成员映射 + `actor` 注入 + 审计） | **继续有效**，且本轮实测宿主已具备登录能力 |
| 裁定 2 | **开源不加密**：本地明文（可审计），企业自行在存储层加密，插件预留加解密接口；**必须向甲方披露「当前明文」** | 继续有效 |
| 裁定 3 | 引入成员身份；通用库写入只留痕不审批；失败与弯路书写摩擦强制 | 继续有效 |

### 5.2 设置页分组（9 分区）

引擎 / 记忆中枢 / 外观 / 存储 / 记忆窗口 / 自动化 / 上下文管理 / 维护 / 另加两个后期挂载块（安装向导、调试中心）。
⚠️ **旧诊断已确认**：设置页 9 分区 key 与顺序被 smoke 守卫硬锁 ⇒ 任何分组改动都属**契约变更**，必须独立成批。

### 5.3 「晕」的根因（旧诊断结论，仍成立）

1. `WorkspaceTab` 是 **2,608 行的单函数**。
2. **没有样式层**：439 处内联 style vs 7 处 className。
3. 同一概念 3–5 种叫法（术语冲突）。
4. 线性膨胀：每个新功能加一个 section / 徽标 / 开关。

⇒ **皮肤化必须先补样式层**，否则换肤只能靠覆盖内联样式（不可维护）。本卷 12 给出「不破锁」的样式层引入路径。
