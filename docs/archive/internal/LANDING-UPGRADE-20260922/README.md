## 2. 八个 skill 各自负责什么

本施工单由以下 skill 共同产出。执行者**不需要**读它们，但要知道每条规则的出处，以便判断边界：

| skill | 在本单中负责 |
|---|---|
| `transitions-motion` | 动效 token 刻度（时长/缓动/位移/缩放/模糊）、用途优先匹配原则、开/关不对称、`catalog.json` 配方索引 |
| `improve-animations` | 审计八类目、发现分级（HIGH/MEDIUM/LOW）、计划模板、**「不该动的要明确标出」** |
| `find-animation-opportunities` | 四问闸门（频率/目的/速度/功能）、**必填的「否决候选」清单** |
| `animate` | 建序（先判该不该动 → 定目的 → 选工具 → 选属性 → 曲线时长 → 中断与退出）、reduced-motion 与 hover 门控随动效一起交付 |
| `apple-design` | 按压反馈在 pointer-down 而非 release、空间一致性（进出同路径）、对称缓动、`prefers-reduced-transparency`/`contrast` 三信号、字体光学分级 |
| `emil-design-eng` | 不用 `scale(0)`、`transition: all` 禁令、blur 掩护不完美过渡、`clip-path` 揭示、stagger 30–80ms、次日复看 |
| `mobile-native` | 平台层 11 条：hover 粘滞、点击高亮、`dvh/svh`、16px 输入、`touch-action`、overscroll、安全区、`user-select`、`theme-color` |
| `animation-vocabulary` | 统一术语（stagger / origin-aware / panel reveal / number ticker / tabular numbers / rubber-banding） |

**本项目已确认稀缺的三条**（skill 里未覆盖，由本页设计约束推出）：

1. **本页禁用 `--ease-bounce` / `--ease-bounce-strong`**。回弹过冲是「俏皮」的语言，与页面声明「无渐变、无圆角、无阴影堆砌」的现代主义/国际主义排版冲突。所有进入动效一律 `--ease-smooth-out` 或 `--ease-in-out`。
2. **本页禁用大面积 blur**。页面全局 0 个 `backdrop-filter`；模糊只允许 `--blur-small (2px)` / `--blur-medium (3px)`，用于跨状态切换的掩护，**不得用于纯淡入**。
3. **本页禁用视差与滚动驱动动画**。这是编辑部式文档版式，正文在阅读中不得位移。
