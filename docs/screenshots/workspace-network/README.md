# 工作区关系卡片树

基于上游 `772a7f26e7fab9ab2f6e649d426b6a73a8b9652b`（3.2.15）。参考 [dsh-context 的 Agent 网络](https://github.com/bowenliang123/dsh-context/tree/fd8e3b80136c000af87ad0871c00a7880ec8d51e/src/client)：`agentTree.ts` 的居中父节点与分排布局、`components/agentGraph.tsx` 的边界曲线，以及 `styles/agentGraph.css` 的卡片比例。布局与渲染按本插件现有数据和 React 接口实现。

节点由圆盘改为方框卡片：标题最多两行，摘要省略显示，完整文字保留在悬浮提示和可访问名称中。曲线连接父卡片底边与主题卡片顶边；共享主题使用虚线。画布按容器宽度排成 1～4 列，100%/适应状态保留可读字号；更多主题和全部工作区通过画布滚动查看，不压缩成难以阅读的小字。范围、数量、缩放控件和图例沿用现有皮肤令牌。

自动化检查：生成源同步、语法、10 个皮肤 smoke 套件、工作区布局/交互回归、多工作区、冻结镜像、宿主 UI 限制与 API 路径检查通过；核心 smoke、水窗口检查与 `npm pack --dry-run` 通过。布局回归覆盖 248～1560px、0～40 个主题，验证节点不相交、连线落点与真实父子归属。

真实宿主检查：基线、仪器、编辑、活水四种外观分别验证浅色/深色桌面与窄窗口，共 12 个场景；桌面 8 个主题的两排卡片完整落在画布内，窄窗口没有页面横向溢出。范围切换、键盘选择、实际缩放、适应复位和拖动滚动通过。经典入口的范围、选中态、复位、窄窗口及中英文长标题压力检查通过。

这些结果是自动化与隔离宿主证据，视觉是否符合使用者偏好仍待人工审阅。未合并、未发布，也未替换日常 DSH profile 中的已安装插件。
