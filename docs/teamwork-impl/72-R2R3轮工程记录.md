**★语义纪律（本轮最重要的设计决策）**：初版工具把 `padding: 10px 14px` 拆成 `var(--dam-radius-lg,10px) var(--dam-radius-xl2,14px)` —— **数值等价但语义污染**（客户改圆角会连带改内边距）。改为**只允许同族 token**（padding/gap → `--dam-space-*`），并加断言⑦「外层 token 均属本族」。

## 三、★本轮抓到的 5 个自身缺陷（全部有硬证据）

| # | 缺陷 | 症状 | 修法 |
|---|---|---|---|
| 1 | **假负路径**（R1） | 用注释包住定义行，解析器仍匹配注释内文本 ⇒ 负路径恒绿 | 改为**真删定义**并先断言锚串恰命中 1 次 |
| 2 | **快照断言**（R1/R2） | 测试写死字节数/行数 ⇒ 每轮改源码就伪红 | 物理量断言改为**不变量**（快照值只打印） |
| 3 | **展开器非递归**（R3） | 原值内含 `var()` 时展开不彻底 ⇒ 零视觉变化伪红 | 改为**迭代到不动点** + 括号配对解析（正则处理不了 `rgba()` 嵌套） |
| 4 | **★锚点在字符串中间**（R3 首轮，最严重） | 锚点 `--dam-space-s17: 56px;` 位于 JS 字符串行中间，插入多行 `\r\n'...',` **截断了字符串字面量** ⇒ `node --check`=1、加载守卫 7/10 | **立即回滚**（备份文件字节级还原 sha16 `E8712BA0A0E092D0`）；锚点改用**行尾锚点**（含 `',`），并加「锚点唯一性断言」 |
| 5 | **TDZ 静默失败**（R3） | 锚点检查块引用了尚未声明的 const ⇒ ReferenceError 被 `Select-String` 过滤掉 ⇒ 检查形同虚设 | 修正声明顺序；**排查时改为不过滤输出**（过滤会吞掉 stderr 异常） |

**⇒ 固化纪律（新增 2 条）**：
1. **给 CRLF 源码插入多行时，锚点必须落在字符串边界**（行尾 `',`），否则会截断 JS 字符串字面量；落盘后**必须立即** `node --check` + 加载守卫，不得等到批量复核。
2. **排查失败时禁止用 `Select-String` 预过滤**：它会吞掉异常栈；先看完整输出尾部再定位。

## 四、★R3 顺带发现的既有缺陷 D9（未修，已排除在替换范围外）

`lib/client.js` CSS 段存在：
```css
@supports not ((backdrop-filter: blur(1px) or (-webkit-backdrop-filter: blur(1px))) {
```
**正确写法**应为 `@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px)))` —— 现写法括号配对错误，浏览器会**整条 `@supports` 判定为无效** ⇒ 其内规则永不生效。
**本轮处理**：R3 工具**主动排除**该处（`@supports` 内是特性检测、不是样式声明），因为替换会「顺手修好」它 —— 那属于**语义变更**，超出 token 化范围。**记入缺陷台账，待后续轮次专项修复**。

## 七、R5 轮（裸 rgba · 82 处 → 55 token）

| 项 | 值 |
|---|---|
| 工具 | `tools/b12-r5-rgba.mjs`（新建） |
| 替换 | **82 处**（白/黑透明度层 60 + 品牌色 22） |
| 新增定义 | **55 个**（白/黑 33 + 品牌 22） |
| 断言 | **7 条全绿** + 锚点唯一 + **负路径自测通过** |
| 字节 | 788,280 → **792,275**（+3,995） |
| CRLF | 8,564 → **8,579** |
| sha16 | `979C922CA8083132` → **`3F0B1CE849541318`** |

**命名**：白/黑透明度 → `--dam-white-NN` / `--dam-black-NN`（NN = alpha×100 整数）；其余 → `--dam-rgba-N`。

**★R5 抓到的 4 个自身缺陷（全部有硬证据）**：
| # | 缺陷 | 症状 | 修法 |
|---|---|---|---|
| 1 | **alpha 归一化用字符串截断** | `alphaNum("0.9")` → `"0."`（**非法标识符**）；且 `0.9` 与 `.9` 映射到不同 token ⇒ 定义值错 ⇒ ⑥ 红 | 改**浮点归一** `Math.round(parseFloat(a)*100)` |
| 2 | **只查匹配起点是否被掩码** | `rgba(var(--tile-rgb),.52)` 含嵌套 `var()`，被误替换成 `rgba(var(--dam-rgba-1, var(--tile-rgb)),.52)` ⇒ 破坏既有引用 ⇒ ⑥ 红 | 改**区间级重叠检查**（逐字符扫整个匹配区间） |
| 3 | **alpha 位替换偏移算错** | 用 `lastIndexOf(m[2])` 定位，命中 rgb 分量里的同形数字 ⇒ 截断到 `dam-tile-breathe` 处 ⇒ ④⑤⑥⑦ 全红 | 改为「最后一个逗号 + 其后空白」精确定位 |
| 4 | **负路径未接线** | 注入的裸 rgba 未进入断言输入 ⇒ 负路径恒绿 | 引入 `outForCheck` 并重建掩码 |

**⇒ 最终收敛决策**：alpha 位 token 化（19 处 `rgba(var(--x), .52)`）**本轮不做**，列入 **R5b 待办**（偏移计算已两次出错，风险高于收益；且这些位置的**颜色源已是 token**，客户改色已生效）。本轮的断言⑦ 已把它形式化为「残留项必须全部是 `rgba(var(...),a)` 形式」，**防止偷偷漏过**。
