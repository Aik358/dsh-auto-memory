## 一、★开工取证（三条决定 scope 的硬事实，全部实测）

| 事实 | 实测 | 影响 |
|---|---|---|
| `data-dam-kind` | **0 处**（全仓 lib/client.js） | sha256 锁定的 schema 里 `imagery`/`aesthetics` 写的选择器是 `[data-dam-block][data-dam-kind="Z"]` ⇒ **纸面可写、实际不可命中**；R10 必须补属性，否则 70 卷判据「作者面 5 键全落」不成立 |
| `data-dam-block` | **10 行 / 10 个值**，与 `LAYOUT_BLOCK_KINDS` 逐条吻合 | kind 可从既有属性值取到；补 `data-dam-kind` 是**加别名**而非新造语义 |
| CSS 段含 `data-dam-kind`/`data-dam-block` | **均 false**（段长 94,295 字符） | 新增属性无 CSS 命中 ⇒ 零视觉变化（62 卷 §二纪律 1） |
| `normalizeLayoutConfig` 段 | `regions`/`slots`/`tokens`/`hidden` —— **无 `blocks` 段** | 前端若直接读 `cfg.config.blocks` 是**死接口** ⇒ 必须先扩契约再消费（顺序不可颠倒） |

⇒ **scope 修正（写明理由，不自创第三解）**：70 卷 R10 的「10b 图片槽挂载」依赖 `authorSurface.imagery`，而该面的选择器要求 `data-dam-kind`；该属性**全仓为零**。故 R10 拆为：**R10a 扩契约（本轮完成）→ R10b 补 `data-dam-kind` 10 处 → R10c 前端消费 → R10d 套件与复核**。

**⇒ 固化纪律新增 2 条**：
1. **「整块替换」类补丁的片段，必须逐行抄回原块的全部内容**（含块末尾的 `}` 与同行），只在其上做「插入 + 有限修改」；**并在工具里加尾部完整性断言**（尾行存在 + 行数守恒 + 关键定义未被吞掉）。本轮 `--dry` 全绿仍打崩源文件，正是因为缺这三条断言。
