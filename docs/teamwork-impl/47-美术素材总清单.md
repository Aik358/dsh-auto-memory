# 47 · 美术素材总清单（PNG · 黑夜/白天两套）

> 缘起：用户 2026-09-27「美术素材你再仔细研究一下，看好一点。背景插画确实需要 PNG。这些 PNG 文件具体需要画哪些东西，总体的清单能给我列一下吗？」
> 落点：素材统一放 @@lib/assets/skin/@@，由 @@lib/skin-assets.js@@ 的 @@file@@ 字段引用（**通路待接，见 §五**）。

---

## 〇、先定三条原则

| # | 原则 | 理由 |
|---|---|---|
| 1 | **只有「美术品」才用 PNG** | 开关/胶囊/徽章/进度条这类**用 CSS 画**：可换色、可动画、矢量不糊、体积为零 |
| 2 | **按宽高比分组，同组才拼一张** | 不同比例拼一起，切出来必然变形 |
| 3 | **每张图必须透明底** | 主题切换靠 CSS 底色，PNG 带底色会在另一主题下露边 |

**⇒ 所以本清单里没有开关、没有图标、没有按钮** —— 那些归 CSS。

| 图纸 | 画布尺寸 | 内容 | 排布 |
|---|---|---|---|

| **Sheet-2** | 1536×1024 | **A2** bg-mindmap | 单张不拼 |
| **Sheet-3** | 2400×600 | **B1 + B2 + B3** | 横向**三等分**，每格 800×600 |

| **Sheet-6** | 600×400 | **C2** illust-sync | 单张不拼 |
| **Sheet-7** | 1600×900 | **D1-D5 五件装饰** | 九宫格式松散排列：左上 D1 山峦(800×400)、右上 D2 星光(400×400)、中左 D5 角花(300×300)、中右 D4 分隔(600×40)、底部横贯 D3 波浪(1200×120) |

**⚠ 拼图三条硬约束**：
1. 格子之间**绝对不要**任何分隔线、边框、投影、色块、间隙
2. 每格内容**居中**且**不超过格子的 80%**（留出切图余量）
3. 每格内容**不跨越中线**（否则切到邻格）

**切分坐标（Lead 执行）**：
- Sheet-3：x=0 / 800 / 1600，y=0，w=800，h=600
- Sheet-4：x=0 / 800，y=0，w=800，h=600
- Sheet-7：按 §一 D 类的 5 个区域裁

## 四、替代方案：装饰件可全部用 CSS

**D1–D5 这 5 件装饰**，其实**都能用 CSS/SVG 实现**，而且效果更可控：
- D2 星光 → 一个 @@<svg>@@ 十字星，随时换色
- D3 波浪 → SVG @@path@@ 或 CSS @@border-radius@@
- D4 分隔 → @@::before/::after@@ + 小菱形
- D5 角花 → SVG 弧形
- **只有 D1 山峦** 建议保留 PNG（层叠剪影手工画费时）

**⇒ 我的建议：D2-D5 用 CSS，只生成 D1。** 这样总数从 14 张降到 **10 张**（A1 A2 B1-B5 C1 C2 D1）。

## 五、⚠ 前提：素材通路目前是断的

| 检查 | 实测 |
|---|---|
| @@assetOf@@/@@SKIN_ASSETS@@ 在 @@lib/@@ 的引用 | **仅 @@skin-assets.js@@ 自己（6 处）**，其余零调用 |
| 静态资源路由 | @@/static@@ 0 · @@express.static@@ 0 · @@sendFile@@ 0 · @@image/png@@ 0 |
| @@package.json@@ 的 @@files@@ | 含 @@"lib"@@ ⇒ 素材放 @@lib/assets/@@ 会被发版带上 |

**⇒ 现在即使给我全部素材，页面也不会有任何变化。必须新增（约 30 行）**：
1. @@lib/index.js@@ 加只读路由 @@GET /api/dsh-auto-memory/skin-asset/<key>@@，白名单只认固定 key，读 @@lib/assets/skin/<file>@@
2. @@lib/client.js@@ 让 @@assetOf()@@ 真正渲染成 @@<img src>@@ 或 @@background-image@@
3. 负路径：key 不在白名单 / 文件不存在 ⇒ 回落占位（@@placeholder:true@@ 分支**已实现**，无需改）
