# 12 · 皮肤线资源插口清单（拿去生图用）

> **ADR-002 的配套**：皮肤线**先做完、留插口**，不等图。
> **实测前提**：现有原型 `docs/teamwork-research/skin/index.html` 有 **10 个具名页面**、**0 个 `<img>`**、**1 个 `<svg>`** —— 即当前是 **100% CSS/SVG 实现**。
> ⇒「插口」不是在既有图上改造，而是**新增一组约定好的槽位**。

---

## 一、先说一句实话：**大部分页面不该配生成图**

**GPT-image 擅长**：插画、氛围背景、质感纹理、角色/场景。
**GPT-image 不擅长**：图标、UI 控件、信息图表、需要精准对齐的线稿。

⇒ 所以下面的清单是**克制**的：**只有 6 张**值得生成。
其余全部走 **CSS 渐变 / SVG 图标系统** —— 更清晰、能跟随主题变色、体积为零。
**不要为了"有图"而生图**：信息密集的界面塞插画，只会让界面看起来杂。

## 三、明确**不要**生成的东西（避免白做）

| 不要生成 | 为什么 | 该用什么 |
|---|---|---|
| 图标（底部导航、按钮、状态点） | GPT-image 画的图标**尺寸/线宽/圆角都不齐**，无法成系统 | **SVG 图标系统**（已有，随主题变色） |
| logo / 字标 | 需要矢量、需要精确 | 手绘 SVG 或字体 |
| 图表（健康度、召回统计） | 数据驱动，静态图会立刻过期 | CSS/SVG 实时绘制 |
| 头像/人物 | 有隐私与风格争议；且是功能性元素 | 字母头像 / 可选 |
| 任何带文字的图 | 模型生成文字几乎必然出错，且无法 i18n | 文字一律代码渲染 |
| 每个页面的背景图 | 10 张背景 = 体积灾难 + 视觉噪音 | 仅 `page-mindmap` 一张 |

## 四、插口的代码约定（三条纪律）

### 纪律一：代码只认 key，不认文件

~~~js
// lib/skin-assets.js（新增，纯数据，不改 lib/index.js）
export const SKIN_ASSETS = Object.freeze({
  'hero.welcome':   { file: '', alt: '欢迎主视觉', size: [1600, 1000], status: 'pending' },
  'empty.library':  { file: '', alt: '记忆库空状态', size: [800, 600],  status: 'pending' },
  'empty.timeline': { file: '', alt: '时间线空状态', size: [800, 600],  status: 'pending' },
  'empty.recall':   { file: '', alt: '召回审查空状态', size: [800, 600], status: 'pending' },
  'bg.mindmap':     { file: '', alt: '思维导图背景', size: [2000, 1400], status: 'pending' },
  'illust.sync':    { file: '', alt: '同步示意', size: [600, 400],  status: 'pending' },
})

/** 取资源：未就绪时返回确定性占位（不抛错、不留白）。 */
export function assetOf(key) {
  const a = SKIN_ASSETS[key]
  if (!a || !a.file) return { placeholder: true, key, alt: (a && a.alt) || key }
  return { placeholder: false, url: a.file, alt: a.alt }
}
~~~

**换图 = 改 `file` 一行。结构代码零改动。**

### 纪律二：占位符必须「像成品」，不能是灰方块

~~~css
/* 占位也必须体面 —— 同尺寸、同构图、同色调 */
[data-skin-slot] {
  background:
    radial-gradient(120% 90% at 30% 20%, var(--skin-color-accent-soft), transparent 60%),
    linear-gradient(135deg, var(--skin-color-bg-elev), var(--skin-color-bg));
  border-radius: var(--skin-radius-lg);
  display: grid; place-items: center;
  color: var(--skin-color-text-dim); font-size: var(--skin-font-size-xs);
}
/* 占位标签只在开发态可见，生产态隐藏（但图未就绪时仍显示） */
[data-skin-slot][data-placeholder="false"]::after { content: none; }
~~~

⇒ 效果：**图到位前后，布局与观感都不塌**，随时可演示。

已在上表给出。**没有尺寸与构图要求，生成回来必然要返工**（裁剪、留白、方向全不对）。
