## 三、★本轮抓到并修复的真缺陷（R10 计数锁）

**现象**：首次落盘后 `[r10] PASS 30 / FAIL 2`——`data-dam-block` 由 **10 → 11**。
**取证**：`'data-dam-block': 'media'` 是 R20 的 `SkinImg` 里**本来就写的**；但 `SkinImg` 当时是**未被调用的干函数**，
因此从未被 R10 的正则命中；**R21 一挂载就暴露**。
**裁定（第 10 条纪律：口径取自权威）**：`data-dam-block`/`data-dam-kind` 是**结构层 block 锚点**
（R10b 明确「10 个 block 节点」），**皮肤挂载点不得引入 block 锚**（语义扩张）⇒
从 `SkinSlot` 移除这两个键，并在片段注释中**显式写明该边界**。
**结果**：`[r10] PASS 32 / FAIL 0`。
