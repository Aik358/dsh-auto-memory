## 二、做什么

把 CSS 区（L1709–L2276）内的**字面刻度值**抽成 `--dam-*` token，**只追加定义、不删改任何既有行**。

| 属性类 | 替换数 | token 前缀 |
|---|---:|---|
| `border-radius` | 84 | `--dam-radius-*` |
| `font-size` | 38 | `--dam-fontsize-*` |
| `gap` | 30 | `--dam-space-*` |
| `backdrop-filter` | 4 | `--dam-blur-*` |
| **合计** | **156** | **57 个 distinct token**（定义块共 75 条） |

替换形态：`border-radius: 8px` → `border-radius: var(--dam-radius-md, 8px)`。
**保留 fallback** ⇒ 即使 token 未定义也零视觉变化，且**展开可完全还原**。

### 2.1 白名单（有意不 token 化，非遗漏）

| 模式 | 数量 | 理由 |
|---|---:|---|
| `calc(Npx * var(--dam-scale))` | 16 | 已是「基准字号 × 缩放因子」**计算式**，再包 token 会让客户改字号时打架；正确做法是基准 px 本身作为 token |
| `blur(Xpx) saturate(Y)` | 21 | 复合滤镜，拆分需改写法，收益低于回归风险 |
| `@supports` 回退串 | 1 | 非纯值 |
