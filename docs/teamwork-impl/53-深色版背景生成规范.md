# 53 · 深色版背景生成规范（白底抠透明法）

> 定稿 2026-09-27 · 用户提出并拍板的方法 · 8 张全部通过肉眼验收

## 一、方法来源（用户原话）

「反正现在背景是白的，我的建议是，你把纯白的部分直接变成透明，然后把剩下的部分直接贴在深色上面，会不会更和谐一点？」

**结论：比 RGB 反相方案显著更优，已采纳。**

## 二、为什么不用 RGB 反相（三轮实验结论）

| 方案 | 结果 | 判定 |
|------|------|------|
| 亮度反相 `v→18+(1-v/255)*200` | 色相保持但**对比度塌陷**，山峦几乎不可见 | ✗ 淘汰 |
| 伽马反相 `v→14+pow(1-v/255,.75)*205` | 同型问题，色相偏橙 | ✗ 淘汰 |
| HSL 明度反相（保色相） | 量化指标漂亮（SD 5.9→12.1、色相 208 保持）但**肉眼仍看不清** | ✗ 淘汰 |
| **白→透明，贴深色底** | 山峦层次自然、无白边、无噪点 | ✓ **采纳** |

**根因**：源图对比本来就极低——6 张背景的明度跨度仅 **0.076**（lmin 0.888 ~ lmax 0.978，取 2%~98% 分位）。任何单调映射都只在 0.076 的窄带里做文章，映射后依然窄；而「白→透明」是**改变合成方式**（alpha 混合），不是压缩值域，深色底本身提供了对比。

## 三、算法（最终版）

```js
// 死区门槛 242 / 满值 150
async function cutWhite(src, dst, { dead = 242, full = 150, q = 90 } = {}) {
  const { data, info } = await sharp(src).ensureAlpha().raw().toBuffer({ resolveWithObject: true });
  const C = info.channels, N = info.width * info.height;
  const buf = Buffer.alloc(N * 4), span = Math.max(1, dead - full);
  for (let i = 0, p = 0; i < data.length; i += C, p += 4) {
    const lum = 0.299 * data[i] + 0.587 * data[i + 1] + 0.114 * data[i + 2];
    const t = Math.max(0, Math.min(1, (dead - lum) / span));
    buf[p] = data[i]; buf[p + 1] = data[i + 1]; buf[p + 2] = data[i + 2];
    buf[p + 3] = Math.round(t * 255);   // 纯白 → alpha 0；景物 → alpha 255
  }
  await sharp(buf, { raw: { width: info.width, height: info.height, channels: 4 } })
    .webp({ quality: q, effort: 5 }).toFile(dst);
}
```

**RGB 三通道原样保留**（不反相、不调色相、不提饱和）。视觉上的「变色」完全由深色底透过半透明像素合成产生。

## 四、死区门槛 242 的由来（关键参数，勿随意改）

实测 6 张背景顶部区域（占画面 15%）的明度分布：

| 文件 | min | p1 | p50 | p95 | max | 均值 | 低于 240 占比 |
|------|-----|----|-----|-----|-----|------|--------------|
| bg-02-forest-tall | 244.6 | 245.6 | 247.2 | 248.2 | 249.8 | 247.2 | 0.0% |
| bg-01-forest | 244.7 | 245.3 | 246.8 | 248.0 | 248.7 | 246.9 | 0.0% |

⇒ **「天空」区带落在 244.6~249.8（落差仅 2.6 单位），景物区 < 240**。门槛取 **242** 天然把两者分开：
- 门槛 246（初版）⇒ 把 2.6 单位的天空噪声放大成可见「暗云」，且文件涨到 3.04MB
- 幂曲线 1.8（试过）⇒ 削掉雾气层与远山，细节丢失，仅 0.44MB
- **门槛 242 ⇒ 天空干净、细节完整，1.90MB** ✓

## 六、复现判据（CR-10）

| 检查项 | 判据 | 负路径 |
|--------|------|--------|
| 尺寸一致 | 深色版与浅色原版逐张 width×height 相等 | 不等即失败 |
| 有 alpha | `metadata().hasAlpha === true`（浅色原版 2 张 ch=3 无 alpha） | 仍 ch=3 即失败 |
| 透明度合理 | bg-04-lake 60.4%（最低）~ bg-03-hero-banner 86.6%（最高） | 全透明/全不透明即失败 |
| 天空干净 | 合成到 #0F1115 后，原「天空」区无可见暗云 | 有暗云即失败 |
| 细节完整 | 山脊、树木、雾气层肉眼可辨 | 平滑成色块即失败 |
| sha256 | 与 `_manifest-dark.json` 逐条一致 | 不一致即失败 |

## 七、遗漏与未决
