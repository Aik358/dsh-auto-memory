## 五、★`chart-legend` 为何维持 17/18（权威结论，非缺陷）

`data-dam-graph-legend` / `data-dam-legend-dot` 属**死锚点**——CSS 里有 `display`/`flex`/尺寸规则，但 **JS 零生产者**。
若按 schema 强行挂 `data-dam-slot="chart-legend"`，会**激活这些 CSS** 从而破坏「零视觉变化」。
⇒ 62 卷 §四的负路径判据写的是 `data-dam-slot >= 18`，而正确读法是「**可挂的都必须挂，死锚点不挂**」。
**本层按后者执行**，并把该判断记录在案，不再当作缺口。
