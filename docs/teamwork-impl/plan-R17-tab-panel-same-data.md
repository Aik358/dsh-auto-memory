## 四、17b 判据设计（真跑，非源码字符串）

1. 真 import `lib/client.js` factory → 真执行 → 取出口中的 `fetchTeamState` / `teamCacheRead` / `teamCacheReset`
2. 桩 `apiGet` 注入两个**不同**的 `state` 响应（第一次 `team.queue=3`，第二次 `team.queue=7`）
3. 两次请求之间**调用同一个共享层**（不是各调一次）⇒ 断言：
   - 第 1 次后两个承载面读到的 **queue 同为 3**
   - 第 2 次后两个承载面读到的 **queue 同为 7**（★同一变化两面同现）
4. **负路径**：构造「一面走共享层、一面走私有取数」的对照实现 ⇒ 断言两者**读到的值不同** ⇒ 证明该判据**能抓出「只改一处」**
