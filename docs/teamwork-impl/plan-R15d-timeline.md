## 二、★口径裁定

| 项 | 裁定 | 理由 |
|---|---|---|
| 头像/徽标 | **不渲染**（个人版无 member）| 49 卷数据映射表明示「个人版不渲染」；member 数据属团队层（R16+）|
| 竖线 + 圆点 | **渲染**（纯几何，不需 member）| 48 卷 L108–L111；圆点色走泳道色 |
| 数据来源 | **前端本地分组**：展开 `kb.lanes[].cards` ⇒ 按 `mtime` 的**本地日期**分组，组内按 mtime 降序 | 不改宿主、不加路由（单写者纪律）|
| 日期格式 | `YYYY-MM-DD · 星期X`（中文）/ `YYYY-MM-DD · Weekday`（英文）| 48 卷 L95 逐字 |
| 计数 | 「N 条活动」= 该组卡片数 | 48 卷 L96 |
| 折叠 | 分组行**可折叠**（点标题行收起该组）| 48 卷 L96 有箭头图标；46 卷 L88「可折叠」|
| 显示条件 | 仅当工具栏视图为 `timeline` 时渲染；`list`/`lane` 回落到 `KanbanBoard` | 48 卷 L71–L75 三视图切换 |

## 四、★安全边界

1. `lib/wb-sidecar.js` 纯 **LF**；`lib/client.js` 纯 **CRLF** / **ES5**。
2. 期望值**逐处自算后相加**（第 7 条纪律）。
3. 断言锚串先核源码确认存在。
4. 计数锁（裸 hex 94 / 裸 rgba 201）**零增**。
