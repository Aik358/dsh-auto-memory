## 〇、★ 先解决的前提：素材通路目前是**断的**

| 检查 | 实测 |
|---|---|
| `assetOf` / `SKIN_ASSETS` 在 `lib/` 的引用 | **仅 `skin-assets.js` 自己（6 处）**，其余零调用 |
| 静态资源路由 | `/static` **0** · `express.static` **0** · `sendFile` **0** · `image/png` **0** |
| `package.json` 的 `files` | 含 `"lib"` ⇒ 素材放 `lib/assets/`" 会被发版带上 |

**⇒ 结论**：即使现在给我 16 张图，页面也**不会有任何变化**。
**⇒ 这正是 28 卷 G07「运行时零实现」的另一半** —— 不只没排版，**整条通路都没接**。

**必须新增**（B12 L2 的前置，约 30 行）：
1. `lib/index.js` 加一条只读路由 `GET /api/dsh-auto-memory/skin-asset/<key>`，读 `lib/assets/skin/<file>`，白名单只认 6 个 key
2. `lib/client.js` 让 `assetOf()` 的返回值真正渲染成 `<img src>` 或 `background-image`
3. 负路径：key 不在白名单 / 文件不存在 ⇒ 回落占位（`placeholder:true` 分支，**已实现**，无需改）

## 四、★ 提示词（复制整段给 GPT-image）

### Sheet-1 · hero.welcome（1600×1000 · 透明底 · 每主题 1 张）

**黑夜版**：
```
深色主题插画，透明背景（PNG 透明底，不要任何色块底），尺寸 1600×1000 横构图。

主体是一棵「发光的记忆树 / 思维星图」：从画面右侧偏下的一个柔和光点（象征你）向外生长出 5 条弧形枝干，每条枝干末端是一簇半透明发光节点，节点内部有细微的文档页/齿轮/心形/日历剪影符号。枝条用 2px 圆头线条绘制，节点用柔和外发光（不要霓虹感、不要强光晕）。

配色：主色蓝 #4A90D9、辅色绿 #48B784 / 紫 #8B7FE8 / 橙 #E8A33D / 粉 #E07B7B，线条与节点整体明度偏高、饱和度适中。背景元素只允许极淡的星点（直径 1-2px，透明度 15% 以下）。

构图硬约束：**画面左侧 40% 必须完全留空**（纯透明，不放任何元素），因为那里要叠文案。主体全部集中在右侧 60%，垂直居中略偏下。

风格：扁平 + 轻立体，现代 SaaS 插画，线条干净，无重投影，无纹理噪点。
禁止：任何文字/字母/数字/水印/签名/人脸/品牌 logo/边框/背景色块。
```

**白天版**：把上面第二段末尾加一句替换掉配色段：
```
配色：主色蓝 #4A90D9、辅色绿 #48B784 / 紫 #8B7FE8 / 橙 #E8A33D / 粉 #E07B7B；线条采用中饱和度实色（#4A90D9 主线条），节点用浅色填充 + 1px 描边，**不使用外发光**（浅底上发光会糊）。背景星点改为极淡的圆点（#4A90D9 透明度 10%）。
```

### Sheet-2 · 三个空状态（2400×600 · 透明底 · 每主题 1 张，横向三等分）

**黑夜版**：
```
深色主题空状态插画组，透明背景（PNG 透明底），画布 2400×600，**横向并列三个独立插画，每个占 800×600，三等分排列**。

左格（0-800）：空书架 / 空收纳盒，格子是空的但轮廓完整，暗示「等着被填满」。用极淡的蓝色线条勾勒，1-2 个漂浮的小光点。
中格（800-1600）：一条未点亮的轨迹 — 从左下角出发的虚线路径，右侧有 3-4 个空心圆点（未来节点），路径用渐隐处理（左虚右无）。
右格（1600-2400）：一个放大镜悬在空白纸面上，镜内是干净的浅色空面，镜边缘有 1-2 个极淡的波纹线。

配色统一：线条与轮廓用 #4A90D9 及其 60% 透明版本，点缀色依次用 绿 #48B784 / 紫 #8B7FE8 / 橙 #E8A33D（左中右各一色）。

**硬约束**：三格之间**绝对不要**任何分隔线、边框、投影、色块或留白间隙 —— 三格必须无缝衔接，从 x=800 和 x=1600 的垂直线切下去，不能切到任何元素。

风格：极简线性插画，2px 圆头线条，扁平，留白充足。整体元素高度不超过 400px，垂直居中。
禁止：任何文字/字母/数字/水印/签名/人脸/背景色块。
```

**白天版**：同上去掉发光、线条用实色 #4A90D9、点缀色用 40% 透明的同色系。

不要任何构图焦点、不要任何符号/图标/文字、不要边框、不要渐变蒙版边。
风格：抽象、均质、无叙事、极简。
