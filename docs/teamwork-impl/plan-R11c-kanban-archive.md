## 三、★改法安全边界（勘察结论）

1. `dedupeCardsPre` 的复合键**不得改动 `section` 字段本身**（`laneOfEntryPre` 依赖它归类泳道）。
2. 复合键分隔符用 **`\u0000`**：`section` 文本不会含它 ⇒ **无碰撞**（比 `'|'`/`':'` 安全，节名可能含冒号如「当前状态(2026-09-10 18:0x)」）。
3. 默认路径**必须**保持 `includeArchive: false`（拍板 C）。
4. 既有守卫锁（L410 / L423 / L450 / L507 / L509）**一律不动**。
