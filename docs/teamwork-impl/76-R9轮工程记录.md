## 三、★本轮最重要的发现：跨层锚点重叠（实测取证）

**实测（脚本 `tools/tmp-r9-overlap.mjs`，取证后已清理）**：`lib/client.js` 中**同时带 `data-dam-region` 与 `data-dam-slot` 的行 = 6**（只带 region 11 / 只带 slot 416）。样本：

| 行号 | slot | region |
|---|---|---|
| 3098 | `board` | `page` |
| 3211 | `detail` | `page` |
| 3615 | `graph` | `page` |
| 5521 | `chart` | `page` |
| 6493 | `head` | `page` |
| 6512 | `nav` | `page-nav` |

⇒ **若 R9 无条件清空未在计划内的节点，就会把 R7 在这些双锚点节点上写的 `display`/`order` 覆盖掉** —— 客户「隐藏 page 区域」会因 R9 的清理逻辑而失效。

**修法**：`applyLayoutSlotsPre` 引入 `lastAppliedSlots` 记账 + `mine` 守卫：**只处理「本次计划内」或「上次本层写过」的节点**，其余节点一律不碰（跨层互不越权）。

## 六、★本轮自身缺陷（4 个，全部有硬证据）

| # | 缺陷 | 根因 | 修法 |
|---|---|---|---|
| 1 | **首版直接落盘无跨层守卫的实现** | 未先测「region/slot 是否落在同一节点」 | 取证测出 6 处重叠 ⇒ 加 `mine` 守卫；已字节级回滚后重打 |
| 2 | 判据 ⑭ 假红 | 断言写 `=== ''`，但产品**没碰**该节点 ⇒ 普通属性为 `undefined` | 断言改为 `=== undefined`（这才是「零改动」的正判据） |
| 3 | 测试崩溃 `Cannot set properties of undefined` | 沙箱 `mkEl(null)` 不建 `__attrs` | 传占位 region 再覆写 |
| 4 | 测试崩溃 `Cannot access 'R4' before initialization` | 上一条语句**缺分号**，下一行以 `(` 开头被 ASI 接成函数调用 ⇒ 变量在自身初始化式里被引用 | 补分号（并把变量改名） |

**⇒ 固化纪律新增 3 条**：
1. **凡新增一层 DOM 消费者，必须先实测该层选择器与既有层选择器的节点重叠数**（本轮 6 处），并为重叠节点设计「本层只碰自己写过的」记账守卫；否则后加层会悄悄废掉先加层的效果。
2. 测试里「产品未碰节点」的断言不能用 `=== ''`（空串只代表显式写过空值）——**未定义与空串是两种语义**，要按被测语义选。
3. JS 测试中「上一行是 `const X = …` 且下一行以 `(` 开头」必须补分号；ASI 会把两行接成一次调用，报出误导性的 TDZ 错误。
