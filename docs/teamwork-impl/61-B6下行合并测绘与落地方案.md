## 三、落地形态（最终）

| 交付 | 文件 | 说明 |
|---|---|---|
| 下行驱动器 | `lib/team-pull.js`（新增） | **纯逻辑 + 依赖注入**；不 import 任何引擎内部、不直接写盘、不联网 |
| 拒绝留痕 | `lib/team-merge.js`（补 1 函数） | `recordRejected(n, reason)` + `rejected()` 查询 |
| 验收 | `tools/verify-team-pull.mjs`（新增） | 4 条判据全部真跑（含负路径） |
| 台账修正 | `16-进度台账.json` | B6 files 改为实际形态 |

**team-pull.js 的注入契约**（这就是「不绕过 Gate」的结构性保证）：

```
createTeamPuller({ engine, fetchJson, conflictCenter, appliers, onApplied, diag, now })
  appliers = { fact(payload), procedure(payload), handoff(payload) }
```

- `appliers` **由 index.js 装配**，指向既有引擎方法（`_factStore.upsert` 等）
- puller 内**没有**任何 `fs` / `path` / 网络调用 ⇒ 想绕过 Gate 也**没有工具可绕**
- 无 applier ⇒ `applyOne` 返回 false 并留痕（**不猜、不写**）
