### 2.2 ★去重（用户裁定：并成一张卡，卡里标「共 N 条」）

**实测问题**：现有看板 1,453 张卡，仅 **108 个不重复标题** ⇒ **92.6% 重复**。
（成因：同一件事被按昨天 / 早晨 / 下午切成多条记录。）

**裁定做法**：同标题合并为一张卡，卡内显示「共 N 条」；细节收在卡内，不铺开。

**验收判据**：
- 正路径：造 3 条同标题条目 ⇒ 只出 1 张卡，且卡上显示「共 3 条」
- 负路径：3 条不同标题 ⇒ 必须出 3 张卡（不得误合）
- 可复算量：合并前后卡片数（1,453 → 实测值）、唯一标题数（108 不变）
