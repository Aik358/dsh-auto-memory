## 二、★口径裁定

| 项 | 裁定 | 理由 |
|---|---|---|
| 成员字段 | `member` / `actor` / `author` **三者任一**（支持字符串或 `{name}`） | 与 R12 统计卡「协作成员」同源 |
| 个人版 | **无三字段 ⇒ `members=[]` 且 `hasActorData=false`** | 「不是有一个叫『未知』的成员」——44 卷 §二 |
| 排序 | `count` 降序 → `name` **码元**升序 | 确定性（不依赖插入序）；★中文次序由 UTF-16 决定，**不可凭直觉猜** |
| `actor=''` | **不筛选**（全量） | 等价「全部成员」缺省态 |
| 筛选与泳道 | **正交**（`filterCardsPre` 只读成员维度） | 44 卷 L65 两个下拉并列；可串联，互不覆盖 |
| 成员名 | 两端空白归一 | 同一人不因空白分裂成两人 |
