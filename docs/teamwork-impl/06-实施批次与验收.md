## B0 · 基线冻结与守门

**目的**：建"零差异"验收的唯一基准。

```bash
# 1) 冻结三个不可变文件的哈希（本仓已实测）
certutil -hashfile lib/index.js SHA256
certutil -hashfile lib/client.js SHA256
certutil -hashfile package.json SHA256

# 2) 记录回归基线（180 套件）
node tests/smoke/smoke-test.mjs
```

**验收判据**：
- `lib/index.js` sha256 与本文档记录一致；
- `lib/client.js` sha256 与本文档记录一致；
- 回归 **180 PASS / 0 FAIL / TIMEOUT 0**。

⚠️ **并发写者告知**：本仓可能存在**其他会话**同时编辑 `lib/client.js`。⇒ B0 的哈希必须在**每批改动前后各取一次**，两次都记录（本次调研实测到过"基线捕获后 6 秒被他人改写"的情况）。

## B1 · 两个身份级缺陷修复（★最高优先，与同步解耦）

### B1-1 技能 id 内容寻址

**改动**：`lib/procedure-store.js`
**代码**：见 05 卷 `3.1（`procedureIdOf` + `ensureContentAddressed`）

**验收判据（三条，缺一不可）**：
1. 同一 title+steps 在**两台不同机器**上生成**相同 id**（单测：跑 `procedureIdOf` 两次，输入相同 ⇒ 输出相同）；
2. 既有条目 id 变更后**仍可被旧 id 找到**（`byId(oldId) || byAlias(oldId)` 命中）；
3. 回归 180 套件全绿。

**风险**：id 变更会让**前端书签 / 引用 / 已导出 SKILL.md 的锚点**失联 ⇒ 必须保留 alias 且**至少保留一个大版本**。

### B1-2 团队项目 ID

**改动**：新增 `lib/team-project-map.js`（见 03 卷 `2.5）+ `index.js` 读取点改一处
**验收判据**：
1. `teamEnabled=false` 时**完全走 `localWsKey`**（逐字节一致的回归）；
2. `teamEnabled=true` 且 git remote 可得 ⇒ 两台机器**派生同一 projectId**（单测：喂两个等价 URL（https 形式 与 ssh 形式）⇒ 同 id）；
3. 无 git remote ⇒ 返回 `stable:false` 且 `describe().hint` 非空（**必须让用户知道**）。

## B3 · 出站队列

**改动**：新增 `lib/team-outbox.js`（见 03 卷 `2.2）

**验收判据**：
1. **幂等**：同一变更 enqueue 两次 ⇒ `size()==1`；
2. **可续**：enqueue → 新建实例 → `load()` ⇒ 内容仍在；
3. **有界**：超过 `maxItems` ⇒ 丢最旧 + 记降级（不无限增长）；
4. **不阻塞**：`enqueue` 是同步返回（用计时断言 < 5ms）；
5. **原子写**：临时文件名含 **pid + 序号**（遵既有纪律，避免第三次踩同型缺陷）。

## B4 · 同步心跳（★关键路径，必须 fire-and-forget）

**改动**：`index.js` `agent/pre-step`（:12590 之后）+ 新增 `lib/team-sync.js`

**验收判据（最重要的一批）**：
1. **pre-step 耗时不变**：`teamEnabled=false` 时与基线**逐毫秒可比**；`teamEnabled=true` 且服务端**故意慢 10s** 时，pre-step 仍 < 50ms（证明没有 await）；
2. **单飞**：并发调用 `tick()` 只有一次真正执行；
3. **最小间隔**：5s 内的重复 tick 被跳过；
4. **永不抛**：服务端抛异常时 tick 正常返回。

⚠️ **这是全项目最容易造成"每轮对话变卡"的地方**。判据 1 必须实测，不能只看代码。

## B6 · 下行合并 + 冲突中心

**改动**：新增 `lib/team-pull.js` + `lib/team-conflict.js`

**验收判据**：
1. **不绕过 Gate**：构造一条"脏事实"，断言它走既有 `upsert` 被拒（计数 +1），**没有直接写盘**；
2. **冲突保留双方**：同一三元组两个 object ⇒ `conflict-added`，双方 provenance 都在；
3. **未知 kind 被拒且留痕**（返回 false + diag）—— 不猜、不写；
4. **拒绝可见**：`recordRejected` 被调用（不是静默丢弃）。
