`lib/team-transport-http.js`（T2 涉密内网通道）**已写好并自测 111 PASS，但没接上**：

⇒ 若不接线就重启，这一块在真机上**永远拿不到 E2 证据**，等于白重启一次。

### 5.2 接线做法（★关键设计：避开 ESM 循环 import）

| 项 | 决定 | 理由 |
|---|---|---|
| 谁调用谁 | `createTeamTransport` 调 `createHttpBackend` | 后者是前者的一个后端实现 |
| **怎么引用** | **装配层注入** `options.createHttpBackend`，**不用顶层 import** | ★两文件**互相引用**（http 后端复用 transport 的 `withPrefix`/`trimSlashes` 纯函数）；ESM 循环 import 会有 TDZ，在本插件**手写模块加载器**下更不可靠 |
| 未注入时 | 仍抛 `transport-not-implemented` | **安全默认**：绝不静默降级到 s3 |
| 已注入但缺 endpoint | 由 `createHttpBackend` 抛 `http-not-configured: endpoint` | **安全红线不变**，仍是构造期响亮失败 |

**安全语义未被削弱**：接线前后**都是构造期抛错、都不降级**，只是抛错的**原因文案**从「未实装」变成「未注入工厂 / 未配置 endpoint」。
