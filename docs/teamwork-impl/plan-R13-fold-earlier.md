# plan-R13 · 看板「展开更早」（13a 分页/折叠 · 13b 持久化）

> 依据（开工前全量读）：**44 卷 L13**（用户原话）、**44 卷 L83 / 46 卷 L124**（折叠条规格）、70 卷 R13 行。

## 一、★44 卷 L13 用户原话（逐字）

> 「得看数量而定… 1. **显示最近的修改和每天的修改，之前的记录进行折叠**；**或者只展示前多少个，后面的折叠，点击后就显示**。2. 增加搜索功能…」

**⇒ 收敛出两件事**：①**首屏只给最近 N**（天/条）②**其余折叠 + 点击展开**。

## 二、★44 卷 L83 / 46 卷 L124 折叠条规格（逐字）

```
【底部折叠条】一行居中：左右各一条 60px 水平细线 + 中间胶囊按钮
按钮文字：「展开更早的 21 天（1,341 条活动）」+ 向下箭头，圆角 999px，深灰底
```

⇒ 契约必须有三个量：**更早的「天数」**、**条数**、**是否还有更多**。

## 三、小轮清单与判据（70 卷：判据「大量卡时首屏不卡；展开后计数守恒」）

| 小轮 | 做什么 | 判据 |
|---|---|---|
| **R13a** | `wb-sidecar.js` 新增纯函数 `foldCardsPre(cards, opts)`：按 mtime 倒序，首屏保留**最近 N 天** | 首屏卡数 ≤ 全量；`folded.days`/`folded.count` 可复算 |
| **R13a-2** | 返回 `visible` / `folded` / `hasMore` / `total` | ★**计数守恒**：`visible.length + folded.count === total` |
| **R13b** | **持久化**：宿主透传 `foldDays`（路由 query）+ `stats.fold` 审计量；前端 localStorage 键名入契约 | 显式 `foldDays=0` ⇒ 全量（等价「展开」）；不传 ⇒ 默认 7 天 |
| **R13c** | CR-10 套件 + 八项复核 | PASS 不降级 |

## 四、★口径裁定

| 项 | 值 | 依据 |
|---|---|---|
| 默认首屏天数 | **7 天** | 44 卷「显示最近的修改**和每天的修改**」⇒ 首屏给一周；且 46 卷图示为 21 天**可展开**，说明默认更短 |
| `foldDays=0` | **不折叠**（全量） | 等价「点击后显示」的终态 |
| 「更早的天数」算法 | `ceil((today - 最早被折叠卡日期) / 1天)` | 与 46 卷「展开更早的 **21 天**」同口径 |
| 「条数」 | 被折叠卡数 | 与 46 卷「（**1,341 条**活动）」同口径 |

## 五、★改法安全边界

1. **只新增纯函数 + `stats.fold`**，不动 `lanes`/`stats.total`/`byKind`（守卫锁）。
2. `wb-sidecar.js` 纯 **LF**；`lib/index.js` 纯 **CRLF**。
3. 计数型期望值**一律运行时自算**（4 次教训后升级：由被插入/被替换文本自身派生）。
4. 断言锚串**先核源码确认存在**再写。
5. 负路径「真删」须去掉 `export` 关键字，断言导出数恰少 1。
