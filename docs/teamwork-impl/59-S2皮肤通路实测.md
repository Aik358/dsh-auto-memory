### 2.1 逐条理由（含「为什么不填」——这是本轮的主要判断）

#### ✅ `hero.welcome` → `slots/hero.welcome.png`（1600×1000 / 1,319,485 B / sha256 `00fb630131c641f0`）
- 尺寸与 12 卷**逐像素相等**（1600×1000），无需裁切。
- 实图为**雪原松林 + 层叠远山**，整体极淡（浅蓝白调），**无任何文字**；主体山脊集中在画面**上 2/3**，
  下 1/3 是大面积留白雪地 —— 与「留出空白放文案」的意图相容（留白在**下**而非要求的**左**）。
- **判定为可接受的偏差**：素材是**既有资产**，不是按 12 卷 prompt 现生成的；左下留白对居中/居左文案牌都可用。
  **若后续严格按 12 卷「左留 40%」重生成，应替换本槽位。**

#### ✅ `empty.recall` → `slots/empty.recall.png`（800×600 / 143,786 B / sha256 `7060fb06686e8aa4`）
- 尺寸与 12 卷**相等**（800×600）。
- 实图为**蓝色线性放大镜**（含一片浅蓝镜面）—— 与 12 卷「放大镜下的空白」**意象直接命中**。
- 构图极简（单一主体居中、四周留白），符合「干净、安静」；无文字。

#### ✅ `illust.sync` → `slots/illust.sync.png`（600×400 / 75,091 B / sha256 `94af028a85af7cc6`）
- 尺寸与 12 卷**相等**（600×400）。
- 实图为**四个圆角方块通过曲线汇聚到中央方块**（蓝/绿/紫/浅蓝四色）—— 表达的是**多端汇聚**，
  与 12 卷写的「两台设备双向箭头」**不是同一意象**，但同属「同步/连接」语义族。
- **判定为可接受的偏差**：仍是**横向构图**（12 卷硬要求），且 600×400 的卡片位能直接放。
  **若后续生成「双向箭头 + 光点流动」版本，应替换本槽位。**

#### ❌ `empty.library` 留空 —— **素材缺失，需美术补**
- **12 卷要求**：空的收纳盒 / 空书架，要有「轻盈、可填满」的感觉，**不能显得沮丧**。
- **现有素材**：`slots/` 里**没有**任何空库/收纳类图；`elements/` 与 `icons/` 里最接近的是
  `elements/tree-stump*.png`（树桩 256×256）、`icons/icon-archive.png`（256×256），
  均为**小尺寸图标**，尺寸差 800×600 一个量级，且语义是「树桩/归档」而非「收纳盒/书架」。
- **判定**：**尺寸不符 + 语义不符** ⇒ 按纪律「不许硬塞」**保持 `file: ""`**。

#### ❌ `empty.timeline` 留空 —— **素材缺失，需美术补**
- **12 卷要求**：**一条未点亮的轨迹 / 路的起点**，暗示「接下来会发生」。
- **现有素材**：`slots/` 里无轨迹/路/点亮类图；`elements/ic-clock-cycle.png`（循环时钟）、
  `elements/ic-calendar-clock.png` 是 256×256 图标，语义是「循环/日程」而非「未点亮的起点」。
- **★ 关键反例**：`slots/empty.timeline.png`（800×600，152,541 B）**确实存在且尺寸正确**，
  但实图是**一个蓝色循环时钟箭头图标放大到 800×600** —— 这是**图标放大的图标**，不是 12 卷要的插画。
  **尺寸对但语义错 ⇒ 仍判定留空。** 这正是不许「凑数填满」的实例。

#### ❌ `bg.mindmap` 留空 —— **素材缺失，需美术补**
- **12 卷要求**：**极淡**的神经元 / 星系纹理，**对比度必须很低**（要压得住前景节点），**单色/近单色**。
- **现有素材**：`slots/bg.mindmap.png`（2000×1400，1,975,882 B）**尺寸完全正确**，但实图是
  **雪原松林山峦风景图**（与 `hero.welcome` 同族素材，`backgrounds/bg-02-forest-tall.png` 同 sha256 `2c034a396e8446d5`）。
- **三重冲突**：① **非单色**（是浅蓝白风景，有明确明度塑形）；② **非极淡**（山脊对比足以被看清，会与前景节点抢注意力）；
  ③ 语义是「森林」而非「神经元/星系」。
- **判定**：**留空**。硬填会把思维导图变成风景图，直接违反 12 卷「要能压得住前景节点」。

### 2.2 为什么不复用「深色版」顶上来？

53 卷产出的 `slots-dark/` 只有 **2 个**：`bg.mindmap.webp`、`hero.welcome.webp`。
经核 `_manifest-dark.json`：`slots-dark/bg.mindmap.webp`（sha256 `5373a3f5beeb68a7`）与
`backgrounds-dark/bg-02-forest-tall.webp` **同 sha256**，即**同一张风景图的白→透明产物**。
⇒ 深色版**不解决**「非单色、非极淡」的问题，只是把白底改成透明；**同样留空**。
（另：深色槽位命名是 `bg.mindmap.webp`，与浅色 `slots/bg.mindmap.png` 目录/扩展名都不同，
本批未引入深色分流字段 —— 12 卷未定义，属新增规格，需另行拍板。）

## 附：本文件自指读回（复算命令）

$files = @(
  "lib/skin-assets.js",
  "tools/verify-skin-assets.mjs",
  "docs/teamwork-impl/59-S2皮肤通路实测.md"
)
foreach ($f in $files) {
  $b = [System.IO.File]::ReadAllBytes((Join-Path "D:/dsh-auto-memory" $f))
  $t = [System.Text.Encoding]::UTF8.GetString($b)
  $crlf = ([regex]::Matches($t, "`r`n")).Count
  $lf   = ([regex]::Matches($t, "`n")).Count
  $sha  = [System.Security.Cryptography.SHA256]::Create().ComputeHash($b)
  $hex  = ($sha | ForEach-Object { $_.ToString("x2") }) -join ""
  "{0,-46} bytes={1,-8} CRLF={2,-6} bareLF={3,-5} sha256={4}" -f $f, $b.Length, $crlf, ($lf-$crlf), $hex.Substring(0,16)
}
