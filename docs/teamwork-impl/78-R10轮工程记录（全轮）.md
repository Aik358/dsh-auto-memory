## 三、实现语义（与 28 卷逐条对齐）

1. **`--dam-block-style`（28 卷 §3.5 方式 C —— 「唯一需要我方配合的契约」）**：作者在 CSS 里声明 `[data-dam-block="list"] { --dam-block-style: timeline }`；我方消费点 = 读 `cfg.config.blocks.<kind>.style` ⇒ 写 inline `--dam-block-style`。**不新增 JS 渲染分支**（符合 28 卷「纯 CSS 消费」的措辞）。
2. **`--dam-block-bg`（28 卷 §3.6 authorSurface.imagery）**：读 `blocks.<kind>.bg` ⇒ 写 inline `--dam-block-bg`。
3. **fail-safe 与既有三段同款**：`ok !== true` ⇒ 整批不消费（与 R7/R8/R9 同语义）；未知 kind ⇒ normalize 阶段留告警且不进配置；畸形入参 ⇒ 不抛。
4. **删除即回默认**：配置删掉 ⇒ 两个属性被 `removeProperty` 清空 ⇒ 零 inline 样式。

## 五、★本轮自身缺陷（4 个，全部有硬证据）

| # | 缺陷 | 根因 | 修法 |
|---|---|---|---|
| 1 | **R10a 把 `lib/layout-config.js` 打崩**（`node --check`=1） | 片段**漏抄原块尾部**（`slots` 定义与循环、`tokens`/`hidden`/`}`）⇒ 对象字面量截断 | 字节级回滚（还原 `95E5B109F17F00BC`）⇒ 补全片段为 16 行 ⇒ 重打；**新增 3 条尾部完整性防御断言** |
| 2 | R10a 两条假红（判据 ③④ 期望值凭直觉猜） | 实测 `blocks`=11、`LAYOUT_BLOCK_KINDS`=4 | 改**运行时自算期望值**并先打印基线 |
| 3 | R10b 假红（判据 ⑨ 字节增量） | 我把插入串长算错（把 10 个差值当常量） | 改**逐行实际 diff 求和**（附 10 行 delta 明细，可复算） |
| 4 | **R10c 工具 `node --check`=1** | 用行过滤删除 `chk(...)` 行时**漏删了它的续行**（`cnt(fnBody, ...)`）⇒ 孤立续行 `Unexpected token ')'` | 删除 3 行孤儿（含 `const fnBody`） |
| 5 | R10c 三条守卫 NG | ① 片段注释里写了 `--dam-region`/`「?」`占位符 ② 守卫用**裸子串计数**（R7 教训重演） | 注释改写为不含变量名；守卫改**代码行形态判据**（过滤注释行后判定）；补真实实测数字 9/10 |
| 6 | R10d 两条 FAIL | (a) `applied` 只计写 style 的节点，media 只写 bg ⇒ 语义不一致；(b) ㉘ 我误以为未知 kind 应部分消费，实为 **`ok=false` ⇒ 整批 fail-safe**（R7/R8/R9 同款） | (a) 加 `wrote` 标志：**applied = 真写过属性的节点数**；(b) 判据改为断 fail-safe 语义 |

**⇒ 固化纪律新增 2 条**：
1. **用脚本按行过滤删除代码时，必须连带删除该语句的续行**（括号跨行的 `chk(...)` 会留孤儿续行，症状是 `Unexpected token`）。判据：删除后立刻 `node --check`。
2. **`applied`/计数类返回值必须定义「计什么」并写进判据**：本轮 `applied++` 最初只挂在 style 分支 ⇒ 只写 bg 的节点不计入，语义漂移。判据：计数的赋值点必须在所有写分支之后（用 `wrote` 标志）。
