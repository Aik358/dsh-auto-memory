# 88 · R16 外观层残余 token 化（JS 逻辑色值族）+ 度量口径纠正

> 依据：goal 目标书「外观层：**裸 hex 归零** + **裸 rgba 归零**（现余 26 / 141）」；既有约定 `var(--dam-x, 兜底)`（R3/R4 定型）。

## 一、★为什么 R4 清了还剩

R4 的口径是「**掩码 `var()` 兜底后的真实使用**」，只覆盖**样式字符串**里的裸色；**JS 逻辑里返回色值的分支**没纳入：

| 族 | 位置 | 例 |
|---|---|---|
| 泳道色函数 | `kxLaneColor(k)` ×5 分支 | `if (k === 'goal') return '#4d6bfe'` |
| 判据徽章 | `criteriaBadgePre` 表 ×3 | `passed: [⋯, '#3aa675']` |
| 主题强调色 | `ACCENT_VALUES` ×3 | `deepseek: '#1d4ed8'` |
| 决策/泳道背景表 | `decBg` / `laneBg` ×6 | `emit: [⋯, '#7fdcb0']` |
| 图节点/SVG | `stroke` / `fill` ×4 | `stroke: '#8b949e'` |
| 其余单点 | 进度条 / 徽标 / 芯片 ×12 | `fill: '#7d8793'` |

## 二、★口径纠正（本轮最重要的发现，全部有实测）

| # | 错 | 实测 | 纠正 |
|---|---|---|---|
| ① | 「裸 hex 现存 94」 | 94 = **块内 20（定义本身）+ 块外 74**，且其中 8 处是**注释里的 issue/PR 号**（`PR #124` / `React error #310` / `issue #100`）——`#[0-9a-f]{3,8}` 会把它们当 3 位 hex | 口径改为：**去注释 + 排除 issue 号 + 分开统计定义行** ⇒ 真·块外裸 hex = **35**（含 2 处 issue 号 ⇒ 真值 **33**） |
| ② | 「裸 rgba 现存 141」 | 141 是**未掩 var() 兜底**的粗数 | 掩掉 `var()` 后 ⇒ **81**（R16 末） |
| ③ | ★`var()` 掩码用 `var\([^()]*\)` | **兜底常是 `rgba(0,0,0,.22)` / `color-mix(⋯)`，内层带括号 ⇒ 匹配不到** ⇒ 把**已 token 化的合法兜底**全算成裸值（首测假数 **276**） | 改**括号配平扫描** `swallowVar()`（支持嵌套 var）⇒ 真值 **81** |

## 三、改法（零视觉变化）

1. **新增 21 个 token 定义**（按语义命名：`--dam-lane-goal` / `--dam-tone-ok` / `--dam-accent-deepseek` / `--dam-dec-emit` / `--dam-graph-node` …）插入定义块尾部。
2. **就地包裹**：每个字面量 → `var(--dam-<语义名>, <原字面量>)` ⇒ token 未定义时取兜底（与原值**逐字相同**）。
3. **★顺序纪律（真缺陷，落盘前拦截）**：必须**先包裹引用、后插定义**。若先生成定义行再包裹，定义行自身也会被裹成 `--dam-x: var(--dam-x, #hex)` ⇒ **自引用循环**（CSS 循环 var 失效 ⇒ 视觉变化）。已加常驻判据 **⑥b**。

## 六、★本轮自身缺陷（4 个，全部有硬证据）

| # | 缺陷 | 根因 → 修法 |
|---|---|---|
| 1 | **自引用循环**（落盘前 dry-run 拦截）| 先生成定义行、后包裹引用 ⇒ `--dam-x: var(--dam-x, #hex)` ⇒ CSS 循环 var 失效。⇒ 调换顺序 + 常驻判据 ⑥b |
| 2 | ★**自引用循环的连锁**：`#1d4ed8`/`#7d8793`/`#d4a94f`/`#e8c584` 在**既有 `var()` 兜底里已出现** ⇒ 若直接 replace-all 会**双重包裹** `var(--a, var(--b, #x))`。⇒ 生成器先自检并打印风险字面量（4 个），顺序调整后自然消解 |
| 3 | **扫描器锚串不匹配**：`const m = maskVar(l)` 的替换目标写错（实际变量名是 `raw2` 的循环里），`maskIssue` 从未被调用 ⇒ `ISSUE_CTX is not defined` | 改为**按行号定位**后替换 |
| 4 | ★**「半修」模式（同一语义两处各写一份判据）**：我在套件里**又手写了一份**裸色测量（14/276），与扫描器（35/81）不一致 ⇒ 套件红。**这正是已固化的「同一语义多处判据必须一次改全」**。⇒ 抽 `tools/lib/appearance-scan.mjs` 为**唯一实现**，两处同源 |
