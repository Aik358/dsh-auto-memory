如何参与How to contribute

不需要先成为"核心贡献者"。一个能复现的 issue 就是有效贡献。

You do not need to be a "core contributor" first. A reproducible issue is a real contribution.

01 / issue
报一个能复现的问题File a reproducible issue

带上 DSH 版本、插件版本、复现步骤和实际 vs 预期。这一步比什么都重要。

Include DSH version, plugin version, steps, and actual vs expected. This matters more than anything else.

02 / pr
提交一个 PRSend a pull request

小步、单一目的、带上验证结果。回归套件是绿的才算完成。

Small, single-purpose, with verification results. It counts as done only when the regression suite is green.

03 / qq
加入交流群Join the QQ group

问题反馈、使用技巧交流，响应通常比 issue 更快。

Feedback and usage tips — usually faster than issues.
