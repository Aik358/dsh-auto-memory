# 面向初次使用者的记忆设置

保留 DSH 白底/宿主深色和全局字体字号。仅调整 iter5 的说明、分组及折叠展示，配置键、默认值、保存路径不变。

- 查找与回忆：先说明主动查找和找到后的使用方式，再选择搜索工具；安装、阈值和索引维护按需展开。
- 记录与使用：明确读取已有记忆与写入新日志是两个独立功能。常用项直接显示；容量、提示词、流程晋升等进阶项可展开。
- 外观与目录：说明文件位置、显示偏好，以及记忆面板字号与 DSH 设置页字号的区别。
- 接续与维护：明确新会话需要确认、免打扰的作用、定时任务需要宿主运行。

术语：注入 → 交给 AI / 带入对话；沉淀 → 记录要点；固化 → 提炼长期记忆；水位 → 上下文使用占比。原配置字段不改名。中文及英文说明在 skins/iter5/settings-copy.js，未添加新的语言选择。

## 验证

隔离 DSH 宿主，1440×1000 桌面和 390×900 窄屏，全部截图均为 **DSH 全局 14px**，无浏览器缩放。15 项宿主断言通过、0 pageerror，包含进阶控件可达、跨分组草稿保留和取消恢复。未修改日常安装或真实记忆数据。

生成器 LF/CRLF 幂等、既有保存/草稿/并发配置回归通过；增加了回忆使用方式不藏入进阶和新标签可访问名称断言。用户可理解程度仍需实际用户反馈，这些自动化结果不代表新手可用性实验。
