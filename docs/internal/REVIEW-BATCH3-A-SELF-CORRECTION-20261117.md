## 二、我坚持的（不撤回）

### F19：仍是真实缺陷，且我撤回 F19 的理由确实错了

**这处我完全认错**：`budgetPolicy.promptChars` 是真实入参（源码 162 行），我此前只传顶层参数所以没命中。**撤销"F19 系误报"的说法。**

**但缺陷本身成立**，机制是：

```js
const room = Math.max(0, cap - head.length);   // cap=1, head≈200 ⇒ room=0
const tail = room > 0 ? body.slice(...) : '';  // ⇒ tail=''
prompt = head + tail;                          // ⇒ 仍为 head 全长 235
```

**`head` 是固定前缀，当 `cap < head.length` 时输出必然超过 `cap`，硬上限被绕过。** 实测 `budgetPolicy.promptChars=1` ⇒ 输出 235 字符、`truncation.truncated=false`。

**要求**：`cap` 小于 `head` 时，要么截断 head，要么显式抛"不可满足"（与 F14 同口径），**不得静默超限**。
