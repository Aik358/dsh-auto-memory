注释原文：`离线实测证明语义不能做阈值判定`。

## 4. 必须做的实验（按顺序，每条给结论）

### 实验 A · 表示层调优（最可能有收益）

**假设**：当前「name + summary + 最近 3 条检查点」的拼接方式淹没在领域词里，
换一种**强调差异**的表示能提升区分度。

至少试这 5 种表示，逐一测 margin 与 top-1 命中率：

| 变体 | 表示 |
|---|---|
| A0（基线） | `name + ' ' + summary + ' ' + 最近3检查点` |
| A1 | 只用 `name` |
| A2 | 只用 `summary` |
| A3 | `name + 最近 1 条检查点`（去掉 summary 的通用措辞） |
| A4 | **去掉领域停用词**后的 name+summary（需先统计出该领域的 IDF 高频词） |
| A5 | 在文本前加**任务类型前缀**，如 `"任务：修复缺陷。` / `"任务：发布版本。` |

**判据**：margin 提升 ≥ 3 倍（从 0.003 → ≥ 0.01）且 top-1 命中 ≥ 4/5 才算「有收益」。

### 实验 B · 分数分布诊断

**假设**：margin 小是因为余弦相似度的**绝对值天然集中**（E5 对中文短文本普遍 0.85–0.92），
问题可能不在排序能力，而在「score 不可解释」。

- 画出 32×32 事件的**相似度矩阵**，看是否存在块结构（同族事件聚在一起）
- 若**矩阵有块结构但 top-1 排序错** ⇒ 说明是**表示问题**，实验 A 有救
- 若**矩阵是一片均匀的高分** ⇒ 说明是**模型容量问题**，E5 这条路到头了

**这一条是决定性的**：它区分「调优能救」和「调优救不了」。

### 实验 C · 二分类 vs 排序

**假设**：我们其实不需要「从 200 个里挑 1 个」，只需要「这两个是不是同一件事」。
后者是**二分类**，难度低得多。

- 用真实标注构造正负样本对（正：同一事件的检查点 vs 该事件；负：不同事件）
- 测 E5 的 `cos(正) - cos(负)` 分布，看是否有可分间隔
- 给出**最优阈值**与在该阈值下的 precision / recall

### 实验 D · 召回率测试（最实用的角度）

**假设**：E5 做不了判定，但能做好召回。

- 目标：从 47 个 active 事件里召回「正确答案」的 **top-5 命中率**
- 实测当前 top-1 只有 1/5，但 **top-5 是多少？**（这是关键数字）
- 若 top-5 ≥ 90% ⇒ **E5 有明确用途：把候选从 47 压到 5，再交给模型判定**

### 实验 E · 与词袋/标识的对照

- 同一批查询，比较三种方法的 top-1 / top-5：
  - E5 余弦
  - 现有词袋 0.34 判据
  - L1 标识层
- **给出「三种方法哪个场景该用哪个」的结论表**
