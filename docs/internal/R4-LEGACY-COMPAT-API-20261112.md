# R4 兼容接口与现行白板职责边界（2026-11-12）

> 本文件最初为设计调查。P6/P7 A1 实现与证据另见 `R4-P6P7-A1-RESULT-20261112.md`；本文件不替代其运行时验收。A1 保留原件，不移动或删除真实记忆；默认路径退出的实际完成范围以 Lead 复核为准。

## 这些公共职责是否属于整体升级

属于。但应按职责拆成三层，而不是把所有旧名字函数都标成废弃。

| 职责 | 现状与归属 | 升级后的位置 |
|---|---|---|
| `writePlanSnapshot` | 白板现行写入口，串接 CAS、锁、用户区保护、归档、索引和设置迁移 | **正式白板接口**；可拆内部模块，不作为旧账本兼容函数 |
| `checkMutationPre`、白板保护 | 白板和账本共用的现行保护 | 保持唯一实现，由正式白板或兼容接口调用，不复制到兼容层 |
| `writeHandoffLedger`、`readLatestHandoff` | 新建旧时间戳账本和读最新旧账本 | **旧账本兼容接口**；默认新文档路径退出后只服务显式兼容调用 |
| `writeFullRaw`、sidecar、看板 | 日历/合并写/白板/账本也在用的通用能力 | 保持独立模块，不标成旧账本兼容、不随退役 |
| 旧文件枚举、旧格式识别、sourceRef | 历史快照的读取与格式适配 | 独立兼容模块；保留原文件，默认 RAG/注入不再消费旧快照 |

## 对外接口的建议

目标文件：`lib/legacy-handoff-compat.js`（名称待实现时定），模块头明确：仅用于旧账本读取、旧格式适配和受控旧写入；新功能走 `LedgerDocSystem`，不新增旧时间戳快照。**兼容接口属于 P6/P7 A1，不在 P5 提前施工。**

接口按调用方需求命名，不把 `_pre` 旧命名带入新契约：

- `readLatestLegacyLedger(args)`：读旧快照；保留 mtime 优先、同 mtime 按文件名排序的现行口径，并显式返回 legacy 来源与缺失/读错区别。
- `listLegacyLedgers(args)` / `readLegacyLedger(args)`：供历史浏览和恢复使用，限制在既有根内。
- `writeLegacyLedger(args)`：只供明确兼容调用；调用现行保护/索引，不允许从默认提示词或 R4 默认写入触发。

兼容模块依赖现有 engine/适配器，不复制保护门、CAS、锁、sidecar 或原子写。正式白板接口保留 `writePlanSnapshot` 的调用语义；其内部可逐步模块化，不因兼容层而退役。

现有 `lib/ledger-doc/index.js` 和 `LedgerDocSystem` 只负责新文档系统；兼容层可作为显式 legacy 读取提供者接给宿主，不伪装成新维护文档、不另造一套默认状态。

## 最小风险实施顺序

1. 先定义兼容模块的导出与调用方，记录原函数的参数、返回形状、错误和排序语义。
2. 新调用方只通过兼容模块；兼容模块可先薄转发，现行保护和旧方法保持原样。
3. R4 默认注入、接续和读取改走新文档；旧入口从默认工具/提示词退出，显式旧调用返回清晰迁移错误。
4. 用兼容读写、R4-off、R4-on、白板单卡/全量、历史恢复做正反路径验收；任何“兼容”不改变原文件字节。
5. 若后续要物理搬移原实现，先处理源码抽取与字节锁，再独立迁移；不在 A1 顺带做大搬迁。

## P6/P7 A1 的实施边界与验收

P6/P7 是同一批兼容/存量保留工作：P6 负责冻结、审计、备份、恢复和默认路径切换；P7 负责显式兼容接口、旧写入退出及旧数据保留。A1 不是物理删除。

| 子批 | 允许范围 | 验收门 |
|---|---|---|
| A1-a 审计/备份 | 当前真实清单、字节数/SHA、独立备份；只读源文件 | 备份恢复字节一致；损坏/缺文件/部分恢复拒绝；不隐藏未覆盖项 |
| A1-b 兼容接口 | 新建旧账本兼容模块；读取、枚举、格式适配；受控旧写入仅显式调用 | 正常旧文件可读；不存在/读取错误区分；排序和字段一致；新文档不误当旧账本 |
| A1-c 默认路径退出 | 新文档接管默认注入/接续/读取；旧快照退出默认 RAG；旧默认写入/旧装配停用 | on/off 均有定义；默认不再新增旧时间戳文件；显式旧调用给迁移指引；不改变真实源文件 |
| A1-d 保护与回归 | 白板单卡/全量、用户区、日历、sidecar、面板与历史恢复 | 现行白板接口和保护不丢；旧文件字节不变；受影响的现有套件和真实宿主通过 |

**与 2.6/2.7/2.8 的分工**：P6/P7 A1 负责旧账本兼容和默认路径退出，不把新文档 WAL 当成旧 `memory_note` 归属/摘要/失败语义已完成。2.6/2.7/2.8 的旧写路径仍需独立合同和验收。

**回滚**：A1 的默认路径切换通过配置或适配器回退；旧源文件不移动、不改名、不物理删除。兼容模块的新增/改线可回滚，旧文件字节保持原样；恢复演练使用隔离副本。
