# 设计补充说明（来自项目既有注释与历史裁定）

- 宿主 DSH 在**同一个模型请求内会多次调用** context 面的 text()，但只投影**最后一次**结果。
  ⇒ 同一请求内的多次调用必须返回**逐字节相同**的内容，否则前一次会被后一次覆盖。
- 「完整版」实测约 **42,480 字符**；「精简版」实测约 **3,696 字符**。
- 精简版内容 = 记忆系统状态行 + 检索指引 + 唤回通知（不含规则段/Tier-0目录/白板/账本/日程/铭文）。
- 完整版内容 = 上述 + 规则段 + Tier-0 常驻目录 + 白板 + 账本 + 日程 + **尾部铭文**。
- 历史裁定：「不能每轮都注入精简版，就算每轮都注入也会浪费一定内容」⇒ 精简版每 3 个模型请求一次。
- 判定「同一模型请求」的现有手段：session 事件里的 `step/start` 事件的 step 号，以及插件自维护的单调计数 `_stepSeq`。
