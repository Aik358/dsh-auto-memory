## 门面契约

- `new LedgerDocSystem({rootDir,enabled:false,...config})` 同步构造；rootDir 只接受当前工作区 artifacts 下的绝对隔离路径，默认 enabled:false。
- 无默认生产事件汇；WAL 仅在显式注入 eventSink 时构造。没有全局注册表或生产写入入口。
- start/stop/reconcile 为 async。默认 start 不创建任何目录，stop 等待本门面跟踪的操作。
- 启用后 start 创建隔离目录、执行 WAL 对账、预热 stamp；返回原始 reconciliation/stamp 结果。
- 已被后续 committed 取代的旧版本返回 attention 但可正常启动；`complete:false` 保留信号。未决恢复或 stamp readErrors 才使 start ok:false。
- `upsertDocument(args)` 走现有 `LedgerWal.execute`，而不是直接绕过 WAL 写正文；committed 后调用现有失效总线，通知失败保留 cache-refresh-failed，不回滚正文。
- `queryHistory(args)` 转调 LedgerHistoryQuery.query；`auditCoverage(args)` 转调 LedgerCoverageAuditor.auditAll 并写隔离报告。
- 停用或尚未启动返回可预测的 `{ok:false,error}`；无事件汇返回 `wal-not-configured`；其他模块仍可按生命周期使用。
