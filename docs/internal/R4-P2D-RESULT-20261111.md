## 实现契约

新模块 lib/ledger-doc/history-query.js 导出：

- `LedgerHistoryQuery({rootDir,eventStorePath,logsDir,archiveDir,timeZone,fs})`：构造隔离查询器。
- `query({from,to,eventId,kinds,cursor,limit,includeQuad})`：返回结构化时间线。
- `queryHistory(options,filter)`：同一实现的便捷入口。
- `parseHistoryTime(value,timeZone)`：解析显式日期或携带 Z/数值偏移的 ISO 时间；无时区的日期时间拒绝，不继承机器本地时区猜测。
- `HistoryQueryError`：参数/游标错误带结构化 `code`。

事件检查点与按日 Markdown 日志按 `at` 正序合并。默认读取 `logs/` 和 `archive/`，可显式禁用 archive；不读取 handoff/documents 当前维护文档作为历史事实。

返回 `items` 含 `eventId/checkpointId/at/kind/text/goal/state/dead/next/sourceRef/opId`，另含 `identityMode/legacyCheckpointKey/targetRevision/recoveryPointer/source/checkpointIndex` 等恢复字段。分页响应包含 `range/coveredSources/readErrors/truncated/nextCursor`。

- `includeQuad:false` 时四段为 null；true 时直接返回持久化字段，不使用展示截断文本。日志没有四段时仍为 null。
- 旧检查点无 checkpointId 时显式返回 null，并附 `identityMode:'legacy-derived'` 与确定性 `legacyCheckpointKey`；不冒充持久化 ID。
- 已持久化合法 checkpointId 原样返回并标 `identityMode:'persisted'`；畸形 ID 进入 readErrors。
- `limit` 为 1～500 整数，默认 100；keyset 游标绑定区间、事件、kind 集合和时区，防止跨查询复用。同一毫秒按事件、检查点序号、来源、原始行序稳定决胜。
- `truncated` 只在当前过滤结果尚有下一页时为 true；`nextCursor` 与之同生同灭，不以最近 5 条代替完整时间线。
- 任意读取/解析错误进入 `readErrors`，同时 `ok:false`；部分日志仍可返回，但不得解释为「无记录」。
- coveredSources 区分 read/empty/missing/error，并记录 recordsRead；缺失日志不是 I/O 错误。
- rootDir 必须位于当前工作区 artifacts 内，实际读取文件经 lstat/realpath 检查，不跟随根外 symlink。
- 只使用 node 内置模块与既有 protocol.js 的纯函数；不调用 memory_recall、eventStorePre 或生产 index.js。

## 调试中修正

- ISO 月份直接传给 Date.UTC → 偏移一个月；改为 month-1 并加 Z/数值偏移等值断言。
- 日期格式化把单日补成三位 → 后续得到第 0 日；改为固定 YYYY-MM-DD 四位年/两位月日。
- 初始 archive 未默认启用 → 按协议默认扫描 archive，可显式 null 禁用。
- 事件 JSON 解析失败仍标 read → coveredSource 改标 error，同时保留 readErrors。
- 初始日志 includeQuad 对 null 解引用 → 无四段日志明确返回 null。
