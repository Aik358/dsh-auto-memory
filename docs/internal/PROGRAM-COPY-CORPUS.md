## 零、任务说明

### 0.1 活动旨趣

开源 DSH 插件（`dsh-auto-memory`）获独家 API 赞助方（`DSHAPI`）倾力支持，注入一笔**模型推理额度**。我们将此项资源以**凭据**为锚，精准回馈给真正躬行实践的社区同人：无论是提炼出可复现 issue 的敏锐洞察者、贡献被合并 PR 的构建者、长期守护代码模块的维系者，还是撰写出严谨可复核报告的研究者。

两条并行不悖的实践主线：

1. **工程演进线**：插件前后端的精细调试与架构重塑（前端系零构建单文件界面，后端系可精细调参的语义检索模型）。
2. **研究探索线**：围绕本记忆系统的复现、反驳、调参及量化评测（公开报告中已冻结若干具体课题，大半仍待洞开与解答）。

### 0.2 命名抉择与遗留冲突解构

- **新定名**：「引航者计划」/ 英文 `Pilot Credits Program`
- **命名意象**：以「引航」寓意在语义记忆与模型调参的未知海域中，凭实证与代码为开源社区拨迷寻路。
- **消解既有冲突**：彻底摒弃「共创」二字，解决与仓库内 `docs/FRONTEND-CO-CREATION.md`（「前端共创计划」）的撞名桎梏，使工程/研究线与前端线的边界各极其致、一目了然。

### 0.3 优化修辞原则

1. **雅致且精炼**：以典雅文辞赋予技术文档深刻的文学质感与思想深度，文字凝练有力，气韵高远。
2. **恪守事实真谛**：语气改写允许重塑节奏、比喻与段落机理，**绝不逾越**数字、事实、规则判据及边界条款之底线（严守第五节、第六节定义）。
3. **秉持笃实风骨**：杜绝浮夸营销腔，以克制陈述替代信念宣言；金句宁缺毋滥，字字千钧。

### 2.3 区块一 · 研究课题

**小标**：探索疆界
**标题**：额度何以助君拨迷寻路
**导语**：八篇公开报告已冻结了一批具象的科学问题。它们静候领航 —— 每一个课题，只需「换一个端点、换一批语料、调整一组参数」，便能推演复现、直言反驳，或向未知更推进一步。

**01 检索选型**
- 现状：3 模型 × 5 分块 × 6 通道 交叉网格对比；BGE-M3 真实层 R@5 = 0.925。
- 额度所能为：更换推理端点、重载新语料重跑网格，以验证此数，抑或证明其局限。

**02 分块策略**
- 现状：最优粒度于合成层与真实层之间发生反转，规律不可外推。
- 额度所能为：于两层补设更丰盈之语料，看清反转之轨迹与内在机理。

**03 检索通道**
- 现状：加权融合赋予真实层 MRR +11.9% 增益，且未引入额外依赖；然权重标定空间尚待开垦。
- 额度所能为：跨端点扫描融合权重与通道贡献，绘制精密的标定曲面。

**04 重排**
- 现状：重排品质获 +13% MRR 提升，惟 CPU 延迟超预算 52–66 倍。
- 额度所能为：探索更轻量之重排器与部分重排策略，确证收益与代价之真正交界。

**05 激活策略（回声陷阱）**
- 现状：单阈值精确率为 0；双通道决策链 precision 0.818 / recall 0.237。
- 额度所能为：召回率尚待破局 —— 借由带标注之对照实验提升召回，且绝不妥协精确率。

**06 注入成本与前缀缓存**
- 现状：完整版 18,291 字符 = 预算之 228.6%；同站缓存命中率落差达 2.96 倍。
- 额度所能为：切换端点并量化缓存行为，验证特定裁剪能否换取更高之命中率。

**07 架构治理**
- 现状：18,525 行巨型文件已解耦拆分为 110 个模块及 158 条依赖边。
- 额度所能为：引入模型交叉审阅模块边界，校验拆分方案能否经受独立通读之考验。

**08 关系型记忆议程**
- 现状：四类记忆对象 × 五个决策阶段，六个可证伪假说仍缺乏实证数据。
- 额度所能为：将假说构建为小型对照实验：固定候选、随机化表达、模型打分结合人工复核。

**区块结语**：上述结论皆呈示于**技术报告索引页** —— 评测、语料与数据全盘公之于众。社区可复现、可反驳，亦可补全未竟之实验。额度存在的意义，是让「万事俱备，只欠端点」不再成为搁浅探索的借口。

### 2.5 区块三 · 三阶额度

**小标**：阶梯额度
**标题**：凭据为标，不凭私交
**导语**：三阶划分唯看「凭据之硬度，历时之长久」：issue 系单次洞察，合并 PR 系一次交付，长期维护系一道轨迹。一切凭据，皆以公开可查之链接为准。

**启航档 · 周额度｜一条 issue 换一周**
- 凭据：一条被确认或已被第三方复现之 issue
- 周期：按周结算，到期可凭新凭据续期
- 适用：初次探索、意在验证特定端点能力者
- 注脚：入门之阶：尊驾仅需证明自己切实发现并清晰阐述了一项问题。

**远航档 · 月额度｜一个被合并的 PR 换一个月**
- 凭据：已合并之 PR；前端共创计划 A / B 档采纳之改动；文档与本地化
- 周期：按月结算，支持一轮完整实验周期
- 适用：改动已融入主线，需长期运行评测与回归者
- 注脚：主力之阶：凭据须系「已载入代码库之实物」，而非「计划筹划之愿景」。

**领航档 · 季额度 + 优先续期｜持续深耕换一整季**
- 凭据：多条合并 PR、长期代码 review、守护特定模块、长期跟进研究主线
- 周期：按季结算，并享有优先续期之特权
- 适用：已在项目深处留下长青轨迹的核心贡献者
- 注脚：领航之阶：重在轨迹之连贯 —— review 记录、模块归属与研究线的持续产出皆为勋章。

**阶梯补充说明**：**三阶之间绝无尊卑高下。** 尊驾完全可能在同月内兼具 issue 与合并 PR；核验时将按当时可出示之最硬凭据取阶。具体额度配额与可用模型，以核验通过后随 API Key 附发之接入指南为准。

**Q2 额度能否私相转授他人？**
决不可。额度强绑定至申领账号及申领时报备之用途，严禁转售、共享或二次分发。易人使用即视同滥用。

严格遵循阶梯走：启航档按周、远航档按月、领航档按季。复核时仅查验该周期内是否有可核验之产出；无产出则降档或停用，有产出则凭凭据顺延至下一周期。

**Q4 此举是否变相设立付费墙？**
绝无可能。插件代码永远开源免费，无任何功能因额度而设锁 —— 纵不发额度，插件亦完整无损。额度仅赠予愿意并肩躬行者，系对「已然动手」者的补贴，而非「解锁功能」之门票。

## 三、章程原文摘要（`docs/CREATOR-CREDIT-PROGRAM.md`）

> 此乃**对内唯一判据**。公开页可优化修辞，章程则掌控规则根基。

**章程概述**：
本插件有两端可供真实参与：**前端**系一套零构建、单文件、可换肤之界面；**后端**系可精细调参之语义模型（BGE-M3 嵌入 + 激活策略），其每一项门限皆可实测。
第 1 期额度由独家 API 赞助方 **DSHAPI（api.dshapi.icu）** 拨划给社区，专注于两类工作：插件前后端之调试优化，以及围绕本记忆系统之探针研究（模型选型、评分标定、合成数据、蒸馏实验）。
额度**按证据下发，不按承诺预支**。每项贡献皆须附带公开可核验之凭据：PR 链接、复现步骤、复现脚本及其输出，或一篇可公开复核之报告。

**赋能理由（三条）**：
1. **前端乃短板，而改进前端无门槛。** 记忆面板 12 页签 + 设置页 8 分组，信息密度高，布局略显拥挤；前端零构建、单文件、纯 ESM，clone 即跑即改。
2. **后端具真实调参空间。** 语义侧车（Python）负责「像不像」，JS 核心负责「该不该」；检索、融合权重、激活阈值、注入预算皆系可测旋钮，每一个皆对应一篇已公开发布的技术报告。
3. **已有先行者证实此路可行。** 一位社区同仁曾引入 54.2 万条真实群聊消息，对《检索选型》报告展开**第三方独立复核**，斩获一个可冻结结论、两个可用数据、两个空结果，并留痕四类方法判定错误。此类功业此前无处申领资源 —— 本计划即为将此缺口衔接。

**三条参与轨道**：

轨道 A · 工程（代码演进）：缺陷修复｜前端界面｜本地化｜工具链
轨道 B · 研究（调参评测）：复现｜反驳｜补全实验｜标定｜合成数据
轨道 C · 观察（洞察报告）：工程调查｜生态对照｜第三方复核

**三条认定铁律**：
1. 同一份贡献绝不重复计档：一个 PR 若已计入远航档，其对应 issue 不再单独计入启航档。
2. issue 必须可复现方可计入；纯建议类 issue 不计档，然仍属有效贡献。
3. 研究类贡献按证据完整度计档：空谈结论者不计档；给出复现脚本 + 结果文件 + 效度威胁者，按远航档起计；若结论被采纳进决策台账或上站为社区报告，按领航档计。

**额度之本质厘清**：
**系**：模型推理额度。用于跑测评、跑复现、跑标定、做合成数据与蒸馏实验，以及在开发中调用模型端点。
**非**：物理算力。本额度**绝不可**用于训练或微调模型权重 —— 它非 GPU 显存时间。凡涉及权重训练之需求，请于 issue 中另行探讨，不占用本计划配额。
额度仅限用于本项目相关之开发与研究，严禁转售、共享、二次分发或用于对外商业服务。

**申领路径**：准备三行 → 私信维护者 → 查验 → 颁发（可限额、可停用之独立 key）。每期设定固定批次处理窗口。

**复核、续期与退场**：

| 环节 | 判据标准 |
|---|---|
| 续期 | 上一周期内有拿得出之真实产出（PR / 报告 / 实验记录），绝不看口头承诺 |
| 降档 | 额度已消耗却无对应产出；或产出与申报用途严重不符 |
| 停用 | 转售、共享、外泄 Key；大规模爬取；违规内容；用途严重背离申报 |
| 退场 | 贡献者主动退出，剩余额度即刻作废，已发表之内容与署名不受影响 |

复核仅考量一事：**获得额度后是否跑出实物**。无产出之解释成本远高于直接降档，故不设听证环节。

**社区报告上站四项准则**：
1. **独立性明示**：标注为第三方独立复核 / 社区报告，与官方技术报告分列，绝不混排进官方列表。
2. **完全可复核**：全文数据须可由随附复现物（脚本 + 结果文件 + 语料统计口径）精确重算；不可复算之数据绝不采信。
3. **机械脱敏**：凡涉及个人与机构之敏感信息须机械脱敏，方法与数据不得因脱敏发生偏误。
4. **留痕求真**：方法修正过程与效度威胁必须完整保留。删改失败与修正痕迹之报告不予收录。
署名：作者署名并链接至其 GitHub / 个人主页。版面：采用站内既有版式而不改写内容；除机械脱敏与链接修正外，本站绝不改写正文、结论与数据。

**红线与边界**：
- 严禁转售、共享、二次分发 Key，严禁用于对外商业服务。
- 严禁用于大规模爬取、刷量及违规内容生成。
- 切勿申领超出自身实际消耗之配额；额度绝非奖品勋章。
- 提交之贡献须系本人独立完成；引用他人成果须严谨标注出处。
- 插件之开源属性与许可（BSD-3-Clause）绝不因本计划发生改变。**付费墙绝不存在**：插件永远开源免费，额度仅倾注给躬行实践之人。

**章程 FAQ 答问**：
- 不申领额度便无法贡献吗？否，甚至恰恰相反：提交 issue、PR、报告皆无需额度，贡献者皆会列入贡献者名册。额度仅仅是将「心向往之而匮缺资源」者接通。

- 额度到期未消耗完将如何？即刻作废，不予结转。周期遵循阶梯（周/月/季）。
- 可否指定特定模型？接入说明中将列明可用模型。如需计划外模型，请于申领时说明用途，单独评估。
- 研究结论版权归谁？归原作者所有。本站仅作收录与署名，绝不改写内容。
