## 2. 4.3 · 时段总结可回读

**目标**：`memory_read` 支持合法 kind `summary`，返回该工作区最新一条时段总结；非法 kind 行为不变（仍报错）。

**Phase 0 必须先核实**：

- `memory_read` 当前 kind 枚举与拒绝分支在哪（按内容搜 `kind` 白名单：log / reflection / user / notes / calendar / plan / archive），记真实行号与本文件三元组。
- 时段总结真实落盘位置：核对 `WS/summaries`（或既有目录）的命名与顺序规则；「最新一条」按什么排序（mtime / 文件名日期）。
- 现有是否已有「读 summaries」实现（可能只在诊断或 consolidation 里）。有就复用，**不要写第二份**。

**验收判据**：

1. 真调 `memory_read({kind:"summary"})`（真 import → 真构造 engine → 真调用工具函数），返回值含最新一条正文与来源路径；**断言返回内容等于磁盘该文件字节**（不得只断言源码含字符串）。
2. 负路径 A：目录为空 ⇒ 明确空态（不抛未捕获异常、不返回别的 kind 内容）。
3. 负路径 B：非法 kind（如拼错 `summaries`）⇒ 仍按现有语义报错，且错误信息能看出合法集合。
4. 隔离变异 ≥2 条：改「最新一条」排序比较符、改 kind 白名单各一条 ⇒ 必须变红；还原后复绿。

## 3. 4.4 · 诊断面读对目录

**目标**：诊断/状态面显示的「时段总结体积」等读数，必须等于 `MEM/summaries` 真实字节数。

**Phase 0 必须先核实**：

- 诊断读数当前从哪个目录取（按内容搜 `summaries`、`diagnostics`、体积/字节计算处），记真实行号。
- `MEM/summaries` 是否存在、是否有 `*-pre` 旧目录混入（有则只统计主目录并说明理由）。
- 是否已有公共「目录字节统计」函数可复用。

**验收判据**：

1. 在隔离目录造 3 个已知字节数文件 → 真调诊断读数函数 → 断言读数**逐字节等于** `sum(stat.size)`（给出实测数字）。
2. 负路径：目录不存在 ⇒ 返回 0（或明确 unavailable），不崩、不读别的目录。
3. 隔离变异 ≥1 条：统计目录改成相邻目录 ⇒ 断言必须变红。
4. 若该读数经 HTTP 路由暴露，给出真实响应片段（隔离宿主或直接调用路由处理函数）。
