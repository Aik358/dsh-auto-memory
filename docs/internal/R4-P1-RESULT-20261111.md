## 实现内容

### P0

- lib/ledger-doc/protocol.js：协议版本、字段格式正则、documentId/eventIds/opId/checkpointId/revision/changeSet 校验、文本规范化、revision、operationDigest、legacyCheckpointKey。
- eventIds 去空、去重、排序；store 另行在合成 events.json 中验证事件存在且状态为 active/paused。
- revision 为 `sha256:<64hex>`：规范化 UTF-8 文本后，仅将固定第七行 revision 元数据值置空再 SHA-256；正文中的 `revision:` 普通行参与摘要。
- canonical 序列化递归排序对象键；相同 JSON 语义跨键序得同一 operationDigest，循环引用 fail-closed。
- artifacts/_r4-p1-fixtures/fixtures/：两份合成文档、合成事件库与 README；不含真实记忆正文。

### P1

- lib/ledger-doc/document-store.js 新增 LedgerDocumentStore；构造只接收当前工作区 artifacts 下的绝对隔离根。
- 首建使用独占临时文件及原子硬链接发布，已存在返回 `document-already-exists`，不覆盖目标。
- 更新支持 title/eventIds/content 区域 `{regionId,beforeText,afterText}`，逐项核对 base 文本。
- CAS 在读当前版本时和 rename 前各检查一次；错误 revision 返回 `document-version-conflict`。
- 更新经同目录临时文件、fsync、rename；写后严格读回并比较完整规范化文本及 revision。
- 相同语义更新返回 `noop:true`，revision、mtime、字节均不变。
- 读取验证 documentId、结构、事件关联及 revision；列表按 updatedAt 倒序、documentId 稳定决胜，并单列 readErrors。
- 非 artifacts 根、非法 ID、文件符号链接和根目录 junction 越界均拒绝；无 os.tmpdir() 使用。

## 调试中发现并修正的隔离实现缺陷

- 源文件生成时换行转义被工具解释成裸换行 → 改用 String.raw 与显式 CR/LF 处理，再通过真实解析与执行验证。
- CRLF 逐字符归一会产生双 LF → 先 CRLF 后孤 CR；真实首建及子进程一致性通过。
- 解析器漏保留 documentId → 补齐并核对文件名身份。
- revision 曾错误忽略正文任意 `revision:` 行 → 仅处理固定元数据行。
- eventIds 区域曾被通用 region 正则误拒 → 接受区域名，并对合法 ID hex 做协议规范化。
- 关联参数不一致可能被 noop 早退吞掉 → 先比较事件集合，再返回 noop。
- 故障桩初版误在写前 CAS 重读抛错 → 改为 rename 成功后抛错，实测 document-readback-failed；不把探针失败归为产品锁问题。

## 明确未做 / 后续边界

- 未改 lib/index.js、lib/event-write.js、lib/event-store.js、lib/shared-state-lock.js；新模块未被生产入口导入，默认不影响既有行为。
- checkpointId 在此仅实现格式校验；持久化白名单、append 返回、重复 ID 冲突与事件 API 读回不属于本新增 store，仍待后续授权接线。
- opId 在此仅实现格式校验和 operationDigest 原语；op-payload-mismatch、跨事件共享与重放属于 P3，不声称已实现。
- 按任务要求未实现锁。CAS 不是跨进程互斥；两个进程可能同时通过检查后分别 rename，最后一写者覆盖前者。真实双写者互斥/不丢更新仍须 P2A 验收。
- 未实现 WAL、changeSet WAL 完整重建协议、RAG、存量迁移、真实接续切换或任何物理删除。
- 本报告只证明隔离 Node 套件；未跑全仓回归、未做真实宿主 UI/生产环境端到端，不将这些结果外推为生产可用证明。
