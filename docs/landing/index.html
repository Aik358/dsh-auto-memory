01核心管线

从对话到记忆注入，四站直达

观察 → 检索决策 → 投递闭环。NLP 关键词与向量化双轨并行，唤起必要性由统一策略管线回答——每一步都有 JS 权威层做最终仲裁，AI 只在边界内干活。

A · 观察

监听对话与工具事件

持续观察每轮对话、工具回包、用户/助手事件，定位有"长期价值"的内容。

  • 用户消息 + 工具结果实时锚定
  • 子代理静默评估（不打断主流程）
  • 闲聊 / 失败进重试队列（5 分钟心跳）
B · 检索与决策

双轨检索 + 两车道决策

先按相关性排序（词法 BM25 保底 / 内置向量 / BGE-M3），再按"该不该打断你"两车道分流。

  • 词法 0GB 保底 → 内置语义 ~130MB → Python BGE-M3 进阶
  • canary 显式唤起 / shadow 仅记录不注入
  • 决策全程可打分复核（A/P/S/H/E）
C · 投递闭环

固定边界注入 + 证据反馈

提示词字节级稳定，前缀缓存持续命中；每次投递留下 delivered/seen 证据喂回决策。

  • 固定边界注入（前缀缓存友好）
  • delivered / seen 证据回流
  • 「唤起回顾」页可逐次打分 + 政策提示
权限分立 决策全程可复核，记忆治理永远在 JS 权威层。 AI 子代理只产出"建议"；是否写入、是否注入、是否唤起——最终决策都跑在 Node 端的 JS 权威层里；任何一次决策都能在「唤起回顾」页追溯原始证据与上下文。

3.1 · 三层记忆体系

三处文件，三种语义

用户级 → 项目笔记 → 每日日志/反思，越往下越新鲜、越往上越稳定。注入策略按这个分层严格区分：静态纪律进 system prompt 保缓存，动态记忆只取最近 1 天，其余按需 recall。

3.2 · 自动沉淀

记忆自己写自己

每轮对话结束，一个小型子代理静默评估本轮内容——长期有价值的主题分组写入今日日志（## 主题（HH:MM） + 要点），长期决策晋升项目笔记，跨项目规则晋升用户级，闲聊跳过。

  • 主题分组：## 主题（HH:MM） + 要点列表
  • 长期决策 → 项目笔记；跨项目规则 → 用户级
  • 失败入队，每 5 分钟重试；15 秒心跳文件证明循环存活
  • 每日写入有预算 + AI 自动压缩——超限不拒写

04快速开始

三步安装，一条命令

前置：安装 DeepSeek Harness 并至少启动过一次 dsh web。

01安装包

在 profile 目录（~/.dsh/profiles/web）执行：

bash
cd ~/.dsh/profiles/web
pnpm add @a9i5k4/dsh-auto-memory

没有 pnpm？npm install @a9i5k4/dsh-auto-memory 同样可用。

02注册到 profile

编辑同目录 package.json，在 dsh.profile.bundles 数组追加：

json
"dsh.profile.bundles": [
  "...",
  "@a9i5k4/dsh-auto-memory"
]

03重启生效

重启 dsh web——侧边栏出现「记忆」入口，进入即触发欢迎向导。

bash
dsh web

↻更新

设置 → 自动记忆页「检查更新」按钮可一键比对 npm 最新版；或直接：

bash
cd ~/.dsh/profiles/web
pnpm up @a9i5k4/dsh-auto-memory

AI 时代 让 AI 帮你装

复制下面这段发给你正在用的 AI 助手即可：

prompt
在 DeepSeek Harness web profile 目录 ~/.dsh/profiles/web 安装 npm 包
@a9i5k4/dsh-auto-memory（pnpm add 或 npm install），
把 "@a9i5k4/dsh-auto-memory" 追加到 package.json 的 dsh.profile.bundles 数组，
然后重启 dsh web 激活插件。

系统要求：dsh web 跑起来即可，Node 内建依赖足够；Python 档可选（用于 BGE-M3 进阶语义档，失败自动回退词法检索）。
