1我们在研究什么

一句话：记忆不只回答「她想起了什么」，还要回答「她为何此刻想起，以及为什么选择不说」。

举个具体例子。同一条记忆：「上周你因为过敏取消了徒步」。

提醒

你在计划下周徒步 → 直接说「上次因为过敏取消了，这次要不要换个安排」

不提

你只是在聊代码 → 完全不提，或只在建议里静默避开

试探

你说「又得改计划了」→ 可能问一句「还是过敏的原因吗」，也可能只是理解语境

沉默

你明确说过不想提这事 → 一句都不说

同一条记忆，四种不同动作。这才是我们要研究的：不是「能不能找到」，而是「该不该说、怎么说、什么时候说」。

2我们需要什么

① 真实的人机对话，不是人对人

与 ChatGPT / Claude / 各类 AI 助手 / BOT 的真实聊天记录。人对人的对话不能直接迁移——人对 AI 的情感表达方式和人对人是不一样的。

② 多轮、跨会话

不是一次问答，是持续了几天、几周甚至几个月的对话。单轮对话体现不了「关系积累」，就没法研究「记忆」这件事。

③ 必须包含你对 AI 的反应 最关键

我们需要的主要不是 AI 说了什么，而是你的反应。下表每一行都对应研究里的一个标注维度：

你做了什么它在我们研究里是什么标签
接着深入聊了这次介入被接受
换了话题没接住
纠正了它（「不对」「我是说…」）错误归因
表达了不满 / 无语 / 被打断感侵入感
说了边界（「不用提醒我这个」「以后别这样」）边界声明（最珍贵）
表达了认可 / 被理解感（「对，就是这个意思」）被理解感

④ 可公开、可脱敏

我们会做完整脱敏（人名 / 地名 / 单位 / 联系方式全部替换）。而且——你可以先自己过一遍，删掉任何不想给的部分。不给的部分我们不要。

3为什么缺这类数据

我们手上有 10,080 条自己的记忆记录，但几乎全是工程内容——写代码、改 bug、发版本。实测扫过一遍：

来源条目数含情绪表达说明
DSH 记忆7,1013%且抽样确认全是误报
WorkBuddy2,3685%同上
Codex5250%—

「误报」是什么意思？命中的条目实际长这样：

「用户确认发布策略：完整项目完成前保持预览命名空间…」

「负路径断言的实现必须真删被检定义…」

都是词面巧合。不是清洗时丢了，是源头本来就没有。

没有这类数据，我们只能靠想象去设计「AI 该怎么回应你的情绪」——那不是研究，是编故事。

4不需要什么

  • 不需要你的真实姓名、地址、单位
  • 不需要密码、密钥、账号信息（请一定先删掉）
  • 不需要商业机密
  • 不需要你写得好看——越日常越好。口头禅、语气词、说一半的话，都是宝

5怎么给

方式 A · 推荐

完整导出

导出聊天记录 → 自己删一遍 → 发给我们。

ChatGPT / Claude：设置 → 数据控制 → 导出数据 → 邮件收到 zip → 解压得 conversations.json

方式 B

只给一半

不确定哪些能公开的话，先发你自己说的话（不含 AI 回复也可以），我们判断。

方式 C

只给片段

只发你标记过的片段——比如你觉得「这次它答得好 / 答得烂」的那几段。

复制粘贴也完全可以。格式不重要，内容重要。

6隐私与撤回

项我们的做法
脱敏人名 / 地名 / 单位 / 联系方式全部替换；你可以先自己删一遍
用途只用于「何时该主动提起一条记忆」这一个技术问题。不画像、不推荐、不商用
不收集身份信息、账号密码 / 密钥、与你无关的第三方隐私
撤回你随时可以要求撤回已提交的语料；我们会从数据集与所有派生产物中删除
回报研究完成后公开脱敏数据集 + 全部代码 + 结论（包括失败的部分）
