# 热叙述体文风守则（跨项目可复用）

> 用途：本项目 README/landing/公告的统一文风规范；**可整套复用到其他项目主页**（如 Ark9canvas、宣传落地页）。
> 设计目标：任务窗口压缩后，未来会话拿本文档即可"一键套用"同一种声音——不用回忆原对话。
> 配套：dsh-auto-memory 的成稿样例见 [NEXT-MAJOR-PROMO.md](NEXT-MAJOR-PROMO.md) 与 [NEXT-MAJOR-README-DRAFT.zh.md](NEXT-MAJOR-README-DRAFT.zh.md)。

---

## 一、人格设定：产品是"她"

全文用一个拟人主语——"她"。她不是"本插件"，不是"系统"，是一个有性格的同事：

1. **可靠**：该想起的自动想起，不必吩咐；
2. **克制**：不抢话、不寒暄轰炸、无人值守时彻底安静；
3. **诚实**：每次想起都交得出证据链，可以查、可以改、可以被忘记；
4. **有记性**：而且记忆长在你家，不带走、不外传。

**主语纪律**：功能行为永远写"她记得/她想起/她交出/她翻页"，禁止"本插件实现了 XX 功能/系统支持 XX"。

## 二、厂商腔黑名单（出现即重写）

"我们利用先进技术""赋能""极致体验""强大功能""智能高效""助力""一站式""无缝""颠覆"。以及一切"我们相信"式宣言腔——判断要用事实的口吻说出，不用信念的口吻。

## 三、金句工具箱

- **判断句**（一句定调）："压缩是旧范式的续命，记忆是新范式的本金。"
- **公式句**（价值一图流）："AI 助手的价值 = 上下文 × 时间。"
- **对仗收尾**（短、平、余韵）："她记得，不必吩咐。/ 现在，换窗口也不必。"
- **否定式转折**（先把读者扎疼）："不是不聪明，是她的思考被压缩成了一段摘要。"
- **排比三连**（清零的三个方向）："压缩即失真，关窗即清零，换工具即归零。"

公式：**金句 = 普通真理 − 废话 ÷ 字数**。每句写完删一遍"的""了""进行"，删完还站得住才留下。

## 四、母比喻系统（贯穿全文，不许混用别家比喻）

dsh-auto-memory 的母比喻是**一本书**：

| 比喻 | 兜底功能（对账锚点） |
|---|---|
| 把一整本书烧掉，只留一句读后感 | compaction 丢细节（有 Astra 公告背书） |
| 写满批注的笔记本 | 结构化交接笔记（任务/目标/已试方案/进度） |
| 合上一页，翻开新的一页 | 窗口 handoff 而非压缩 |
| 笔记还在手边，随时翻回去 | 全量归档可搜索 + 按需检索工具 |
| 书页间飘出的批注/齿轮/日历徽章 | evidence 链（消息/工具输出/反思） |
| 一句话就能让她忘 | 记忆可删、可审计、归用户所有 |

**本金利息律**：比喻是利息，功能是本金。每个比喻必须能对着功能清单兑现；功能没落地，当天删掉那句比喻。宣传永远不说功能兜不住的话。

## 五、段落骨架模板（万能五拍）

1. **场景钩子**：第二人称"你"+ 具体瞬间（"聊到一半，窗口满了"）——不写"用户在遇到……时"；
2. **扎疼**：点破损失的本质（"为什么修错了、哪条路走不通，全在火里"）；
3. **转折**："她不这么办 / 从第一天就不信"；
4. **机制一句话**：功能名 + 一句人话（不堆参数）；
5. **余韵**：金句或短句收尾，留白。

用户故事用**具体时间与具体动作**（周一/周三/周五），禁止"用户 A/某天"。

## 六、排版与节奏

- 叙事段落负责抒情；**表格、命令块、配置 JSON 保持工程冷静体**，一个形容词都不许混进去；
- 短段落，两三句一段；金句独立成行加粗；
- 数字少而准：出现一个就要对一次账（130MB/563MB/0GB、十三个里程碑、四段式），宁少勿错；
- 每个大节允许一句意象做小标题的影子（如"烧掉的书，留不住读后感"），但小标题必须仍能让人猜出本节内容；
- 一篇材料里金句不超过三句——金句多了，每句的分量都在贬值。

## 七、诚实守则

1. 竞品表述尊重官方口径（引 Astra 用官方原文口径：experimental、笔记跨窗口、归档可搜索）；
2. 不暗示不存在的功能；实验中的特性必须标注（如"大版本新增"章在发布前用占位说明）；
3. 限制与已知问题保留原文、不许宣传腔覆盖（诚实是这个人设的一部分）；
4. "我们不做什么"与"我们做什么"同栏展示——克制写成性格，不写成免责声明。

- [ ] 金句 ≤3，每句删废字后仍站得住
- [ ] 表格/命令冷静体，与叙事段隔离
