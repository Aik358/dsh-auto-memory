1. **全灰白无色**：22 个共用 span 全部只吃 `.gf` 的白系渐变+白边（rgba(255,255,255,.x)），
   没有任何品牌色——用户原话"怎么连颜色都没有"。
2. **非当前步元素塌缩**：所有 art 类型的 span 全部塞进同一个 `[data-dam-tour-art]` 容器

   动画语言脱节。
4. **store 步形不似**：三小条 11px 白片浮在主 stage 上方，与"三层玻璃板"的
   呼应关系没有建立（比例太小、无透视、无厚度）。

## 2. 重做方案（方向不变，实现推倒）

**架构改造（必做）**：`[data-dam-tour-art]` 只渲染**当前步一个**图形
（现在是一个容器塞 22 个 span）。渲染器按 `step.art` switch 输出对应 DOM。

**统一材质基底（修无色）**：所有图形共用 `.ga`（glass art piece）基类：
- 本体：`linear-gradient(135deg, rgba(233,240,255,.34), rgba(233,240,255,.10))`
  + **品牌色 tint**：`box-shadow: inset 0 0 18px rgba(126,164,255,.28)`（每步可换 hue）
- 边光：`border: 1.2px solid rgba(255,255,255,.62)` + `inset 0 1px 0 rgba(255,255,255,.7)`
- 高光斑：每片一个 `::after` 椭圆白高光（左上 30% 处，blur 2px）
- 投影：`filter: drop-shadow(0 6px 14px rgba(10,20,60,.35))`

**每步图形重设计（比例基于 150×150 orb-wrap,主体约 56×56,悬浮于主 stage 上方）**：

| step.art | 图形 | 关键结构 | 动效（专属,常驻循环） |
|---|---|---|---|
| store | 微缩三层玻璃板 | 3 片 34×10 圆角片,各自 preserve-3d 厚度(translateZ ±3px),与主 stage 同角度旋转 | 三片依次轻浮动(相位错开 0.5s) |
| inject | 注入光滴 | 竖圆角针(10×34)+顶端悬浮小球(8px,呼吸发光) | 小球上下浮动,针身光泽扫过 |
| bell | 通知铃 | 圆顶(30×26)+底板(38×7),圆顶内一个小球舌 | 整体左右轻摆(±6°,3s) |
| calendar | 日历叠页 | 34×30 圆角方块+顶部两个装订环+页缝线 | 每 4s 翻页一下(top 半片 rotateX 翻动) |
| link | 双连环 | 两个 22px 玻璃环交叠,交叠区亮 | 两环相向缓慢旋转(方向相反) |
| engine | 棱镜核 | 32px 旋转 45° 圆角方+中心 10px 亮核 | 中心核呼吸发光(1.8s) |
| radar | 雷达环 | 外环 42/内环 22 同心+中心点 | **扫描线旋转**(conic-gradient 遮罩旋转,2.2s)+中心点脉冲 |
| rocket | 阶梯塔 | 三层阶梯+顶端光点 | 光点上升消失→从底部重来(1.6s 循环) |
| bubble | 玻璃泡 | 32px 球(radial 高光偏左上) | 浮沉+微微形变(border-radius 呼吸) |

**灵动性总要求**：每个图形都有**专属常驻动画**（不是只入场一次）；入场沿用
`dam-core-pop`（0.4s 回弹）；主 stage 的 conic 光扫同步映射到图形的 ::after。
