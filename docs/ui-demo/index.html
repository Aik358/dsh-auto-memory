为什么是四段式
三段式（状态 / 目标 / 下一步）会把失败经验挤掉，于是「同一个坑踩三次」成为常态。 我们把它拆成四段，给失败留一个固定栏目，交接时强制写下来。

这条时间线保证什么、不保证什么
✓
保证：写入路径上的 actor 不可伪造 —— 记录里写了是谁写的，就是谁写的。
✕
不保证：这不是防篡改级。任何能读到记忆文件的进程，都可以绕过本插件直接改盘上内容。
口径：审计级追溯（谁写了什么、什么时候），非防篡改级。
存储与加密 · 主动披露
◔
记忆数据本地明文存储（开源可审计）。企业如需加密，由客户自行在存储层加密， 我们预留加解密接口。
我们不做端到端加密的宣称 —— 说了做不到比不说更糟。开源意味着任何人都能自己核验这句话。
