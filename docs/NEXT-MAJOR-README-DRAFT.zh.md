## 烧掉的书，留不住读后感

每一个用 AI 干正事的人，都经历过同一时刻：聊到一半，窗口满了，她"忘了"。不是不聪明，是她的思考被压缩成了一段摘要——像把一整本书烧掉，只留一句读后感。为什么这个方案修错了、那条路走不通，全在火里。

dsh-auto-memory 从第一天就不信这件事只能如此。她把记忆放在窗口外面：该想起的自动想起，不必吩咐；想起的每一条都有出处，可查、可改、可删。

现在，我们把这条路线推到最后一块拼图——上下文将满时，她不再压缩自己，而是**合上一本写满批注的笔记，翻开新的一页**。笔记还在手边，随时翻回去。

**压缩即失真，关窗即清零，换工具即归零——这三件事，从这里开始不成立。**

## 为什么是插件

2026 年 9 月，GPT-6 Astra 把「上下文管理」作为旗舰实验特性发布：笔记跨窗口保留，历史归档可搜索，上下文快满时倾向交接而不是压缩。

我们读到公告时很平静。这不是威胁，是背书——头部厂商用一整个旗舰发布，验证了我们做了十三个里程碑的判断：**压缩是旧范式的续命，记忆是新范式的本金。**

区别只有一个。它锁在一家厂商的旗舰档位里，带着 experimental 的标签；我们把它做成开放插件——**你机器上的任何模型，今天就有一份。**

| | GPT-6 Astra / Codex 实验特性 | dsh-auto-memory |
|---|---|---|
| 可用性 | 单厂商旗舰、experimental | 开源插件，DSH 任何模型即装即得 |
| 笔记 | 跨窗口 keep notes | 四段式交接 ledger，用户可直接读改 |
| 归档 | 早期窗口可搜索 | 本地全量归档 + 词法/语义双臂检索 |
| 检索 | history/_context 工具 | memory_search / memory_note 门控代理工具 |
| 所有权 | 厂商侧 | 全在用户盘上，治理式写回可审计 |
| 分级 | 绑定订阅档位 | 0GB 词法 → 130MB 内置语义 → 563MB Python 进阶 |

## 一个星期

周一，你交给她一个调研，中途关机。

周三，你换了台电脑，顺手把默认模型也换了。她接上的不是"抱歉，我不记得了"，而是上周的进度、三条已经试过的死路，和下一步。因为交接笔记在，原始记录可搜，记忆跟着你走。

周五，你随口问："你为什么记得这个？"她给你看：哪条消息、哪次工具输出、哪一次深夜反思写下的。你可以让她把这条记得更牢，也可以让她忘了那个。

**她记得，不必吩咐。你若要她忘，也只是一句话。**

## 她怎么记

三层记忆，各管一摊：用户级规则（跨项目 who you are）→ 项目笔记（这个仓库的约定与决策）→ 每日日志（今天发生了什么），外加一层结构化**每日反思**（成果/教训/下一步）。静态纪律进 system prompt，字节级稳定，前缀缓存持续命中；动态记忆走运行时快照，只带最近一天的日志与反思，其余按需取回。凭证与密钥，永远被拦在提示词之外。

每轮对话结束，一个小型子代理静默做一次"要不要记"的判断：值得记的主题分组写进日志，决策晋升项目笔记，规则晋升用户级记忆，闲聊跳过。失败进队列，五分钟重试，十五秒心跳证明自己活着。每日有预算，超限时 AI 合并去重后再写——她记得节制。

## 她怎么想起

**不靠模型"记得去查"。** 市面上的记忆方案，要么要模型主动调一次检索，要么要你手动粘贴上下文——忘了调，记忆就等于不存在。这里是 Host 侧的联想中间件：对话进行时，相关记忆在模型开口之前就被检索、决策、注入下一个环节。已发出去的请求不可改写，所以注入走固定边界——前缀缓存永不失效。

想主动问也行：自然语言提问，她自动扩展关键词扫全部记忆层，会话式回答、标注来源；`memory_recall` 天然跨工作区，别的项目的日志、笔记同样可达。

面板「工作区」页签把这一切画成一张关系图：中心是工作区，分支是主题，虚线是共享——你的记忆第一次有了形状。

## 她怎么长大

- **30 天蒸馏**：一个月前的日志被蒸馏成可复用的结论写进项目笔记，原文归档保底——AI 不可用时原样归档，绝不丢一个字。技能与用户级/项目笔记永不参与蒸馏。
- **技能固化**：高频流程固化为 checklist，匹配对话自动附上；注入形态分三级（完整步骤/摘要/提示），高风险场景自动降级为提示。90 天没用自动归档，可置顶。
- **每日反思**：结构化复盘，第二天第一次会话主动呈现。晨/午/晚的问候会提起你当天最重要的工作；离开超过一小时回来，面板自己打开，带着近期摘要等你。
- **日历**：对话里出现截止日期和约定，她自动记下；**没完成的事会持续出现在后续会话里，直到完成**。日视图、紧急度、地点、提醒——她的记性比大多数人类同事好。

## 她怎么交接【占位：大版本发布时替换为实装说明】

上下文将满时，她不再把整本书烧成一句读后感，而是写下**四段式交接笔记**——任务状态、目标、已试过的方案与失败原因、进度与下一步——合上这个窗口，翻开下一个。完整的历史与工具输出落进本地归档，随时可搜；她还能主动调用 `memory_search` / `memory_note`，按需翻回去查任何细节。

配 token 水位感知：快满时，提示你开新窗口交接，而不是默默压缩。

## 她不做什么

1. 不替 Host 决定压缩——窗口是宿主的领地，她只负责交接；
2. 不上传任何记忆——三店全在你本机，外部扫描只读；
3. 不用记忆操纵你的语体——注入永远声明"背景事实，非表达示范"；
4. 不做黑箱——每条记忆有证据直达，每次投递可回放；
5. 不做全家桶——只做记忆，边界清晰才可信。

## 你随时可以查账

每次"要不要想起"的决策都带完整证据链，唤起回顾页按 A 该激活 / P 只预取 / S 应抑制 / H 有害 / E 改目标五档复核打分；三个写入工具全过写入门禁——GBK 乱码 34 特征全表、复读退化、外部 AI 画像 JSON、base64 残留，一律拒写并给中文回执；设置里的「扫描脏 token」一键体检全部记忆文件，只报位置、不看内容。

**信任不是权限问题，是习惯问题——她把每一次想起都摊开给你看。**

## 安装（一条命令）

> 前置：安装 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 并至少启动过一次 `dsh web`。

在 **profile 目录**（`~/.dsh/profiles/web`）执行：

```bash
cd ~/.dsh/profiles/web
pnpm add @a9i5k4/dsh-auto-memory
```

然后编辑同目录 `package.json`，在 `dsh.profile.bundles` 数组追加：

```json
"@a9i5k4/dsh-auto-memory"
```

重启 **dsh web** 生效（侧边栏出现「记忆」入口）。

> 没有 pnpm？`npm install @a9i5k4/dsh-auto-memory` 同样可用。
> pnpm v11 限制安装发布不足 1 天的版本：当天发布想立即更新，在 profile 目录 `pnpm-workspace.yaml` 加 `minimumReleaseAge: 0`，或装显式版本。

### 语义引擎（可选但推荐）

内置 JS 语义档（e5-small q8 ~130MB）需要推理库 `@huggingface/transformers`（随主包作为可选依赖自动安装）。若 pnpm 因安全策略拦截原生脚本（`ERR_PNPM_IGNORED_BUILDS`），执行一次批准后重装即可：

```bash
pnpm approve-builds
pnpm add @huggingface/transformers
```

装完重启 `dsh web`，向导的语义引擎步会自动检测到就绪（SHA256 校验 + 推理自检）。词法检索 0GB 永远兜底，不装也能用（仅召回精度较低）。

### AI 时代安装法

复制下面这段发给你正在用的 AI 助手即可：

```text
在 DeepSeek Harness web profile 目录 ~/.dsh/profiles/web 安装 npm 包
@a9i5k4/dsh-auto-memory（pnpm add 或 npm install），
把 "@a9i5k4/dsh-auto-memory" 追加到 package.json 的 dsh.profile.bundles 数组，
然后重启 dsh web 激活插件。
```

### 更新

```bash
cd ~/.dsh/profiles/web && pnpm up @a9i5k4/dsh-auto-memory
```

设置页「检查更新」可比对 npm registry 最新版，registry 安装支持一键更新。

## 面板与向导

十个页签：工作区（关系图）/ 日历 / 接续 / 记忆中枢 / 日志 / 笔记 / 反思 / 唤起回顾 / 检索 / 存储。

首次启动自动播放**欢迎向导**：每步一枚 Office/Fluent 式液态玻璃应用图标（注入青蓝、问候暖金、日历青绿、引擎紫蓝、雷达天青、完成珊瑚金），各配专属动效；每个功能当场开关、立即生效；语义引擎检测/下载/自检内联在向导里完成；外部记忆来源实时扫描、逐源勾选。中途关掉也不慌——最后一步会告诉你每个开关在设置的哪个分区。设置 → 外观可随时重看。

## 工程内核

- **零运行时依赖**：Node 内建模块之外无任何依赖；
- **前缀缓存友好**：提示词字节级稳定，不反复重编码历史；
- **限额 AI**：自动沉淀每日 ≤8 次带冷却，记忆有用但不烧预算；
- **集中式存储**：全部记忆收在 `~/.dsh/memory/workspaces/` 一个根下，任意会话可读。
