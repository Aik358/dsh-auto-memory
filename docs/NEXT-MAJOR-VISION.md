## 1. 产品论点

**AI 助手的价值 = 上下文 × 时间。** 今天几乎所有 AI 的记忆都死在上下文窗口里：压缩即失真，关窗即清零，换工具即归零。

dsh-auto-memory 的终态：**给 DSH 里的任何模型一个不死的记忆**——有结构、可检索、会成长、可审计、归用户所有。

GPT-6 Astra 把「上下文管理」（结构化笔记跨窗口、归档可搜索、按需检索、handoff 代替压缩）作为旗舰模型的实验特性发布（`features.context_management.experimental_mode`，2026-09-03，closed beta in config.toml）。**我们把同一条路线做成开放、模型无关、可审计的插件能力。** 这不是跟随，是背书：头部厂商用整个旗舰发布验证了"外置结构化记忆"才是正解，"反复压缩成摘要"是被淘汰的旧范式。

## 2. 四个连续性 + 两个横切面（终态的全景账本）

> 2026-09-06 修订：与 README「功能全景」逐节对账后的版本。**每个轴先列已落地的完整清单，再列大版本增量**——未来任何会话改写愿景/宣传前，先拿本节与 README 再对一次账，别凭印象写。

### 2.1 当下连续——窗口内（已落地）
- **主动联想零指令**：Host 中间件持续观察对话情境，相关记忆在模型开口之前被检索、决策、经固定边界注入下一环节——已发请求不可原地改写，**提示词字节级稳定，前缀缓存永不失效**（这是与"模型记得去查"类方案的根本分野）
- **智能检索**：自然语言提问，AI 自动扩展关键词扫描全部记忆层，会话式回答并标注来源；`memory_recall` 天然**跨工作区**，其他项目的日志、笔记同样可达
- **注入内容全出口中和**（0.1.39）：`{{模板变量}}` 再也炸不了轮次
- **无人值守/夜间自动托管**（22:00-08:00 可调）：不注入欢迎语/寒暄/行为指令、日历提醒同步静默——token 花在正事上
- M-CM 增量：M-CM4 水位感知

### 2.2 窗口连续——跨上下文交接（M-CM 主战场，对标 Astra）
- 已有地基：M8 接续卡片、M7 evidence store + 词法/语义双臂索引（JS e5-small / Python BGE-M3）、`memory_read`/`memory_recall` 工具面、三层记忆体系的按需取回注入策略（静态纪律 system prompt + 动态记忆运行时快照）
- M-CM1 **四段式交接笔记**：任务状态/目标/已试方案+失败原因/进度与下一步——低成本先行
- M-CM2 **主动检索工具**：`memory_search` / `memory_note` 注册为门控代理标准工具（CUA 插件已验证工具机制；注意 ctx.get() 坑）——从被动吃注入升级为按需查归档，即 Astra `history`/`_context` 的插件版。**整个大版本最值得做的一件事**
- M-CM3 **原始归档可搜索**：完整历史+工具输出落本地归档（全量+索引），命中"没被笔记捕获的细节"；**归档入库必须走同一套卫生闸门**（§2.6），外部脏数据不能因新特性混入
- M-CM4 **水位感知**：上下文快满时推 handoff 提示而非继续注入；host 若暴露压缩预告事件则在压缩前自动写交接笔记（否则向 DSH 提 feature request——插件只助产，不替 host 决定压缩）
- 终态画面：上下文将满时，Agent 不再"把书烧了留一句读后感"，而是"合上一本写满批注的笔记，翻开新的一页——笔记还在手边，随时翻回去"（Astra 原话：even if that information wasn't captured in its notes）

### 2.3 时间连续——跨周期成长（已落地一整条链，别小看）
- **自动沉淀**：每轮对话结束子代理静默评估——长期价值主题分组写日志（`## 主题（HH:MM）`）、决策晋升项目笔记、规则晋升用户级记忆、闲聊跳过；失败进队列每 5 分钟重试（15 秒心跳文件证明循环存活）；每日预算 ≤8 次带冷却，超限 AI 合并去重后写入不拒写
- **AI 发散固化**（memory_consolidate）：阶段性通读近期日志，发散提炼值得升格的要点——与每轮"记流水"互补
- **30 天蒸馏与召回边界**：旧日志蒸馏进项目笔记，原文 archive 保底，**AI 不可用时降级为原样归档，绝不丢信息**；技能固化/用户级/项目笔记**永不蒸馏**——蒸馏只把"过程流水"换"可复用结论"
- **技能固化全链**：高频流程固化为 checklist，匹配对话自动附上，跨会话验证后晋升（记忆中枢页签审批）；注入形态分级 checklist/excerpt/hint，**高风险场景自动降级 hint**；90 天未用自动归档、可置顶
- **每日反思**：结构化复盘（成果/教训/下一步）落在独立反思层，每日首次会话主动呈现前一日反思；晨/午/晚时段问候提及你当日最重要的工作；**暂离超 1 小时回来，记忆面板自动打开送上"欢迎回来"+近期工作摘要**
- **日历——AI 替你维护**：从对话识别截止日期/约定自动入日历（calendar_add），**未完成事项持续注入后续会话直到完成**——这条本身就是一线上线的"跨会话连续性"特性；日视图 07:00-22:00 时间轴、地点/提醒字段、紧急度语义色
- M-CM 增量：交接笔记进入同一时间轴，窗口切换也有复盘

### 2.4 工具连续——跨产品迁移（已落地 + 大版本补叙事）

### 2.5 横切面一：控制面——一切皆开关（已落地）
- 欢迎向导分步引导：每步一枚液态玻璃图标+专属动效，**开关即写配置立即生效**；语义引擎三级检测/下载/自检内联在向导里（SHA256 校验+推理自检）；外部来源实时扫描逐源勾选；中途关闭先落"完成提醒"步（关不掉的困惑不存在）；可随时重看

### 2.6 横切面二：卫生面——生产级信任（已落地）
- **写入门禁**：三个写入工具全过 sanitizeForWrite——GBK 乱码（34 特征全表）、复读退化、连续重复行、外部 AI 画像 JSON 特征、base64 残留，全部拒写并给中文回执；追加 8000 字/条、全量改写 20 万字上限、追加前与文件尾部近 60 行去重
- **凭证/密钥永远过滤在提示词之外**
- **脏 token 扫描器**：设置→调试中心一键扫描用户级/项目/日志/反思，按行区间报告（只报位置不含正文）
- **唤起可查**：每次激活决策带完整证据链，唤起回顾页按 A 该激活/P 只预取/S 应抑制/H 有害/E 改目标五档复核打分，判定队列汇总成政策提示

## 4. 终态用户故事（README 叙事骨架）

> 周一，你让 Agent 调研一个方案，中途关了电脑。
> 周三，你换了台机器、顺手把默认模型也换了。打开 DSH，她接上的不是"抱歉，我不记得之前聊过什么"，而是上周的进度、三条已试过的死路和下一步——因为交接笔记在，原始记录可搜，记忆跟着你走。
> 周五，你问她"你为什么记得这个？"，她给你看 evidence 链：哪条消息、哪次工具输出、哪次反思写下的，你可以 pin、可以改、可以删。

## 5. 我们不做什么（克制的边界，同样写进宣传）

1. 不替 host 决定压缩策略——只助产 handoff，窗口是 host 的领地
2. 不上传任何记忆——三店全本地，外部来源扫描只读
3. 不用记忆操纵语体——注入永远声明"背景事实，非表达示范"
4. 不做黑箱——每条记忆有 evidence 直达，review 时间线可回放，脏数据有扫描器
5. 不做全家桶——记忆插件不做日程替身、不做 RAG 框架，边界清晰才可信
