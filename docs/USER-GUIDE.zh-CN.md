## 1. 安装与入口

- 安装:`pnpm add @a9i5k4/dsh-auto-memory`(或在你使用的 DSH 插件市场搜索 dsh-auto-memory),**装完重启 dsh web**(manifest 注入面需要重启加载)。
- 入口:左侧栏底部的 **记忆** 按钮(齿轮/设置按钮旁边那一排)。点击打开记忆面板,内含页签:**概览 / 白板 / 语料精修 / 设置**(设置也可以从系统设置的插件区进入)。
- 数据都在本机:`~/.dsh/memory/`(工作区记忆)与 `~/.dsh/dsh-auto-memory-pre.json`(配置,发布版为 dsh-auto-memory.json)。

## 2. 第一次启动

- 首次启动会播放**欢迎向导**,每项功能当场可开关,建议先跟一遍。
- 向导提示下载**内置语义模型**(约 130MB,multilingual-e5-small,本地离线运行)——不下载也能用,只是召回退化为词法排序。向导没弹或想重看:控制台执行 `window['dsh-auto-memory-pre.openWelcomeTour']()`。
- 之后随时打开记忆面板 → 设置 逐项调整。

## 3. 设置页总览(每组怎么调)

设置页左侧分组导航:**自动记忆引擎 / 记忆中枢 / 外观 / 存储 / 记忆窗口 / 自动化 / 上下文管理 / 维护**。

| 分组 | 关键项 | 说明与建议 |
|---|---|---|
| 自动记忆引擎 | 总开关(associativeMemoryEnabled) | 关闭即整插件休眠;默认开 |
| | 注入模式(activationEmitMode) | **shadow**:只记录不打扰(默认,最稳);**canary-explicit**:命中可信度高的回忆才显式注入;**active**:全部注入。先从 shadow 用起 |
| | 候选方案(candidateScheme) | balanced 3×40 / dense 6×20 / custom。查询越复杂越可调 dense;日常 balanced 即可 |
| | 决策冷却/增量 | 高级项,一般不动 |
| | 语义引擎模式 | 见下文 §4 |
| 记忆中枢 | 每日日志/项目笔记/用户级记忆的写入与路径 | 一般不动;看数据存哪可来这里 |
| 外观 | 主题色/密度/字号 | 纯视觉,随意 |
| 存储 | 记忆文件位置/清理 | 慎用清理 |
| 记忆窗口 | 注入预算、唤起条数上限 | 觉得 AI 总被记忆打扰就调小注入预算;觉得想不起来就调大 |
| 自动化 | 自动沉淀、定时固化/30 天蒸馏(consolidateSchedule/maintainSchedule,默认 09:30/10:00)、暂离问候(awayMinutes,0=关)、无人值守 | 固化/蒸馏建议保持默认开;定时器可改点 |
| 上下文管理 | 交接白板开关(handoffEnabled)、水位阈值(waterThreshold)、接续相关(自动接续) | 见 §5 |
| 维护 | 诊断、日志 | 出问题时先用 |

设置改动即时保存(写 `~/.dsh/dsh-auto-memory-pre.json`),无需重启。

## 4. 语义引擎

下拉四个档位(记忆面板 → 设置 → 自动记忆引擎 →「语义引擎模式」):

- **auto(默认)**:内置 JS 语义就绪即用,否则词法保底——最省心。
- **lexical**:强制词法(不下载模型也能选它)。
- **js**:内置 JS 引擎(multilingual-e5-small,~130MB)。选了但模型没下载会提示「实际生效:词法兜底」——点旁边 **⟳ 检测** 或下方引导卡下载,完成后自动启用。
- **python**:高级引擎(BGE-M3 int8,~563MB,本地 Python sidecar),召回质量最高,需要引导式安装(创建 venv+下载模型,全程向导)。**装不上不影响其他档位**,换回 auto/js 即可。

不确定时:**auto + shadow** 就是最稳组合;看到「词法兜底」提示就说明语义资产没就绪,⟳ 检测会自动弹安装引导。

## 5. 上下文管理

**交接白板(实验特性,默认开?)**:让 AI 把项目全貌写成白板 PLAN.md、阶段产出写四段式交接账本,跨窗口续命。设置 → 上下文管理 可开关。

**水位感知**:面板「白板」页签顶部显示当前会话 token 水位(官方计量)。达到阈值后 AI 会收到交接建议、自动补写账本。

**一键接续(手动)**:白板页签 →「一键接续到新会话」。流程:刷新仪式(旧 Agent 先更新白板 PLAN 与账本)→ 取材料 → 创建新会话(沿用**工作区/模型/思考档位**/预设)→ 接续材料作为首条消息预载 → 自动切换。**材料分层**:第0层指令+白板节选 / 第1层最新账本 / 第2层近期线程(最近 20 条 × 700 字,保留角色与工具标记)/ 第3层旧会话完整转写文件(新会话 AI 随时 read 回读)。

**自动接续(推荐,免按钮)**:设置 → 上下文管理 →「自动接续」开关(默认开)+ 阈值(默认 0.8)。插件常驻监听:**水位 ≥ 阈值 且 harness 权威 running 位在轮次边界转为 false(会话真的空闲了)** → 右下角弹确认卡:**同意**=立即接续 / **拒绝**=本轮跳过(同一边界不再提示)/ **30-40 秒无操作**=视为挂机自动接续;接续前先跑刷新仪式。触发后默认 30 分钟内不重复;阈值 0.5–0.95 可调(0.5 便于演示)。

> 注意:自动接续依赖官方会话接口,若提示「remote.session 不可用」,请重启 dsh web 后重试。
> 「新会话落到未分组工作区」/「没沿用模型」已在 2.2.4 修复(需要重启 dsh web + 硬刷新页面)。

## 6. 记忆工具

在对话中,AI 具备(不需要你记忆,但了解一下有好处):

- **memory_log / memory_note / memory_user**:写今日日志 / 项目笔记 / 跨项目规则
- **memory_recall**:跨工作区检索记忆(含交接白板 scope=handoff)
- **memory_consolidate / memory_maintain**:做梦式固化 / 30 天蒸馏(通常自动跑)
- **calendar_***:日程管理——AI 会主动从对话里提取截止日期记入日历并在后续提醒
- 自动沉淀:每轮对话结束,插件自动评估并把有长期价值的内容写入日志——**你永远不需要记得说「记一下」**

## 7. 常见问题排查

| 现象 | 处理 |
|---|---|
| 提示「词法兜底/未就绪」 | 记忆面板 → 设置 → 自动记忆引擎 → ⟳ 检测;按引导下载 JS 模型或装 Python 向导 |
| 「一切就绪」与「未就绪」同屏 | 已修复;若旧版本遇到,升级 2.2.2+ 并刷新 |
| 一键接续报「harness 未提供 remote.session」 | 重启 dsh web(注入面需重启加载);仍不行检查版本 ≥2.2.2 |
| 新会话落到「未分组工作区」/ 没沿用模型与思考档位 | 已修复(2.2.4:create 传 workspaceId、模型取自 request/header);升级后需**重启 dsh web + 硬刷新页面** |
| 自动接续没触发 | ①开关是否开(默认开)②阈值是否已到(白板页签看水位)③会话是否真的空闲(running 位已转 false,长任务跑着不会触发)④是否在 30 分钟冷却内 ⑤需已重启过宿主 |
| 自动接续确认卡没等到我回复就跑了 | 这是挂机兜底:30-40 秒无操作视为无人值守,自动接续;不想被自动带走就点「拒绝」,同一边界不会再问 |
| 设置页整体消失 | 旧版 bug,升级 2.2.2+ |
| 侧栏一堆插件按钮消失 | 可能与其它往侧栏注入按钮的插件冲突(如 dsh-mobile 桌面浮层),到插件管理停用嫌疑插件 |
| 想反馈/拿日志 | 日志:`~/.dsh/dsh-auto-memory-pre-diagnose.log`(子代理熔断/跳过等事件也在内);QQ 群见 README |
| 记忆乱码/重复 | 记忆写入口有卫生闸门;仍异常可到 存储 分组清理对应文件(先备份) |
