# E8 功能待办清单（真缺失功能，非样式问题）

来源：E8 双向类名核对抓出的孤儿类，经 Lead 裁决分为四批。本文件记录**第二批（feature-todo）**。

## E8-T1 · lanes 视图缺「今日」竖线（`.lane-today`）

| 项 | 内容 |
|---|
| 类名 | `.lane-today`（3 条 CSS 规则，L5319-5320 / L5417） |
| 原型行为 | lanes 视图里画一条贯穿纵向的虚线标记「今天」，标签显示「今日」 |
| 现状 | `renderLanesViewPre` 全文件 **0 处** today 相关逻辑 —— **真功能缺失** |
| 影响 | 用户看不出「当前进度在时间轴上的位置」，lanes 视图失去时间参照 |
| 建议 | 在 `renderLanesViewPre` 里按 `Date.now()` 计算 today 在 lane 内的横向位置，插 `.lane-today` 元素 |
| 验收 | 真 Chrome：DOM 里存在 `.lane-today`，且其 `left` 值落在 lane 可视范围内 |

## E8-T2 · 窄屏导航按钮缺失（`.navbtn`）

| 项 | 内容 |
|---|
| 类名 | `.navbtn`（4 条 CSS 规则，L5015-5017 / L5385 / L5395） |
| 原型行为 | 窄屏（<1024px）时左轨/右栏折叠，出现导航按钮打开抽屉 |
| 现状 | E5 只做了「窄屏隐藏 grip + 右栏 fixed 覆盖」，**没有导航按钮** |
| 影响 | 窄屏下用户无法主动打开/关闭左轨与右栏（只能被动看默认态） |
| 建议 | 复用 E5 已有的 `@media (max-width:1023px)` 分支，加 `.navbtn` 触发抽屉 |
| 验收 | 真 Chrome 1024px 视口：`.navbtn` 可见且点击后抽屉态改变 |
